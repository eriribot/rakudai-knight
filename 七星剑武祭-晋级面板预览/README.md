# 七星剑斗祭 · 晋级面板预览

双击 `index.html` 即可打开，无需安装依赖。默认显示“本局赛程”：沿用 MVU 玩家档案和破军选拔引擎，展示已有角色、头像、选拔记录与资格状态。

赛事面板已打入正式[小手机 v1.3.29 B1](../世界书规则/MVU/落第骑士-小手机-v1.3.29-B1-头像更新.json)：终端赛程页可登记全国赛对阵、多人赛果和直接晋级，面板读取本局账本播放。独立预览新增「全国赛 · 已登记赛果」虚构样本；演示操作不写入真实存档。

## 本局赛程

- 默认是独立的“选拔进行中”样本。切换“资格已登记 · 已出线”→“查看七星剑斗祭分区”→“演示抽签后的界面”，查看六名本局代表进入 32 人演示签表。
- 分区图为主入口，点击对局或“定位我的比赛”打开 XY&Z 风格大屏。玩家可准备正文行动；展开“预览用：演示赛果回填”查看 WINNER 和下一轮变化。改判会清除受影响的后续赛果。
- 可切换选拔同分、他校已出线 OC、一辉模式。代表资格读取已保存的资格名册，不从积分或完整账本自动推导；MVU 待保存时暂不确认。一辉模式沿用现有参赛身份，他校 OC 读取所属学园资格。
- “读取 MVU JSON”在本机读取 `stat_data` 本体、`{stat_data}` 或 `{state,source,pending,incomplete}` 快照，不上传、不写回。独立预览可通过参数传入现有头像显示配置。
- 代表资格存于 `场景.七星剑斗祭.资格名册`；全国赛读取同级的 `比赛` 与 `晋级记录`。本局破军代表名单按同一名册筛选，尚无对阵的席位保留待公布。正式大屏显示已保存赛果，独立演示按钮只用于虚构样本。

## 原著回放

- 切换 A—D 区查看对战大屏；切换“晋级总览”查看连线；“参赛名单”查看完整32人名单，包含驹城与新留。
- 主屏下方选择具体对局，或点击“本场原文依据”阅读记录。
- 点击进度圆点，或“播放晋级”，逐轮显示赛果；播放到准决赛时进入冠军页。
- 点击晋级总览对阵卡进入大屏，再用“本场原文依据”看证据；点击名单中的选手看原著记录。
- WIN 表示实战胜出；ADV 表示晋级资格确认；取消、不战晋级与未记载赛况分别显示。

18 名选手有姓名，14 个席位未具名。展示位置按已知晋级关系重排，不表示官方种子顺位。“16强争夺·32→16”是首轮的晋级目标；诸星标记为首轮止步。史黛菈一对四是接续C区比赛补办的B区首轮，随后第二、三轮取消。所有历史档案在弹窗中直接展示完整原著赛果。

`data.js` / `app.js` 为原著回放。`session-ui.js` / `session-ui.css` 为本局流程，`session-bracket.js` 仅维护离线演示签表。`mvu-model.mjs` 实际调用正式 `deriveTournament`，并由 `build-mvu.mjs` 打包成可直接双击运行的 `mvu-model.js`。`build-portraits.mjs` 从终端共用头像清单同步本地人物与别名；暂无头像使用姓名首字。
