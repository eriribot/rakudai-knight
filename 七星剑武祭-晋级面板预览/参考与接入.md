## 正式终端接入（v1.3.29）

赛事面板已打入 `scripts/黑白ADV轮盘终端` 的[小手机 v1.3.29](../世界书规则/MVU/落第骑士-小手机-v1.3.29.json)。从原有「选拔赛程与决斗」进入「七星剑斗祭·赛事面板」，并可返回原页维护选拔登记事务。包按 component 模式生成，不打整卡，旧 v1.3.28 保留。

- 本局面板使用当前 `stat` / `view`，读取玩家身份、OC 头像、选拔名册、我的实际比赛与资格状态，沿用现有头像服务和选拔引擎。
- `stat_data.场景.选拔赛` 仍是校内积分选拔；没有新增全国赛业务 schema。真实全国赛签表缺失时显示待抽签，不编造本局对手、不锁定原作胜者，当前不支持全国赛签表写回。
- 「原著回放」提供 A—D 分区晋级树和 XY&Z 风格对战大屏，包含 B 区史黛菈一对四；历史赛果不会写入本局。
- 天音、平贺、叶暮姐妹与既有头像共用资源清单。37 人头像加盾框的 38 个图床文件已[核验 HTTP 200、PNG 与本地 SHA-256 一致](../resource/knightavatars/research/20261013-tournament/host-verification.json)。

本轮交付验证限于离线构建与检查。真实酒馆尚未导入验收，不能据此宣称实时变量刷新与宿主交互已实机通过。安装步骤见[终端 QUICKSTART](../scripts/黑白ADV轮盘终端/QUICKSTART.md)。

## 保留的独立演示

本目录仍可双击 `index.html` 打开。`RK_MATCH_PREVIEW.setSnapshot(snapshot, {avatarUrl})` 只读取快照，不监听或写回酒馆；“完整账本”是明确标记的虚构 288 人样本。独立 demo 可演示资格、抽签、赛果传播和改判清理，这些演示按钮不代表正式终端已实现全国赛写回。

资格判定沿用 `deriveTournament(stat)` 的名册、实际比赛、积分和完整性；不能把 `eligible` 当作已获资格名单。完整赛季、无名额边界同分、当前快照已保存等条件仍适用。自捏角色的行动与赛果以实际游玩为准，B 区特别赛不默认触发或取胜。

此前独立预览已核对角色身份、完整账本、同分、等待 MVU、他校、一辉唯一性，以及 32 席唯一、赛果传播和桌面/窄屏显示；这些记录不能替代新版的真实酒馆导入验收。

本次沿用 `sillytavern-embedded-ui` 路线与现有终端构建，未引入外部组件或动效库。比赛人数、轮次和特别赛时序见[原文核对](原文核对.md)。
