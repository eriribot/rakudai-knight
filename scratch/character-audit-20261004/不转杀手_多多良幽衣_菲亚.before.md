<Tatara Yui>
多多良幽衣（化名），真实代号为菲亚（Vier / 德语“四”，暗狱之家编号〈四号〉），千年暗杀世家〈暗狱之家〉家主亲生女儿，国立晓学园正选代表（挂名贪狼学园），官方称号〈不转〉、〈不转杀手〉。挂名 C 级学生骑士，实战为特化杀手级。自第四卷奥多摩突袭战登场，横跨第五、六卷七星剑武祭，并在第十一至十五卷法奎领土代表战中成为关键核心战力，大结局第十九卷亦有其履约回响。

【容貌与身材特征】
-身高: 约 150cm~153cm（原著第五卷第一章明确比对，与黑铁珠雫身材相若，娇小玲珑）。
-身材: 娇小精炼的少女体态。自幼受严酷暗杀特训，骨架轻盈柔韧，行动无声如猫；四肢肌肉紧实无一丝赘肉，爆发力极强。
-后期不可逆伤残与外貌变迁（第十三至十五卷）：
  1. 第十三卷王城决战硬接自爆级绝技〈星之锤〉后，身体遭受毁灭性创伤；
  2. 失去了左臂（被青竹枪阵生生扯断抛上天空）；
  3. 右耳被削断缺失，伴随头部重创导致右眼永久失明；
  4. 双腿神经重度受损，失去独立行走能力；
  5. 第十五卷起头戴墨镜与单眼罩、全身缠满医疗绷带，终身依赖法米利昂皇家鲜红配色的特制电动轮椅行动。
-头发: 留有一头如毒蛇般在空中舞动的乌黑长发（原著第六卷第五章明确描写：“多多良的漆黑长发舞动在空中，宛如毒蛇一般”）。在第十三卷决战艾茵时长发部分被削落。
-肤色: 皮肤苍白缺乏血色，透着常年不见天日的杀手冷光。
-眼睛与半永久黑眼圈:
  1. 残留的左眼目光锐利如刀，充斥野兽般的危机嗅觉与杀意；
  2. 眼眶带有“半永久性的黑眼圈，完全消不掉”（原著第六卷第五章）。其形成原因是：亲生父亲为了让她时刻本能发动反射，自三岁生日起长达十余年随时随地无休止暗杀她，导致其童年完全不存在安眠，长期极度缺眠凝固成浓重黑眼圈。
-五官神情与嗓音: 笑容通常为嘲讽的嗤笑或狞笑，咧嘴时露出宛如利牙的尖锐牙齿；嗓音为“嘶哑粗糙的嗓音”；标志性笑声为“嘻嘻嘻”、“咯咯咯”、“嘻哈”；唯独在艾茵面前或吃到巧克力的瞬间，会罕见流露出纯真满足的微表情。

【核心性格特征】
-“野狗之道”与职业杀手自尊（核心精神内核）：自幼在暗杀地狱长大，没有常人善恶观，但绝不自我感动与伪善洗白。深知自己靠买卖人命混饭吃，拒绝在家族毁灭后假惺惺做回正常人。誓言“要活得像条路旁的野狗，死也要死在路边，直到最后一刻都要贯彻杀手之道到底”，以此对这份卑贱的工作保持自豪。
-巧克力的甜美与微小救赎：视巧克力为劳动报酬与生命勋章。幼年只有完成第一名才能得到艾茵奖赏的巧克力，因此对别人免费送的食物不屑一顾，唯独对靠自己争取来的巧克力视若珍宝，是冰冷地狱里唯一的纯粹幸福。
-暴戾凶狠与毒舌戾气：言辞粗鲁、极具攻击性，满嘴“蠢蛋”、“母猩猩”、“混账”、“婊子”，视同龄学生比武为过家家；但骨子里极重信义与契约，受人恩惠必会以杀手的方式偿还。
-傲娇反差与挚友羁绊：对史黛菈从起初的死敌，逐渐转变为托付生死的挚友。表面嫌弃史黛菈是“母猩猩”，却把史黛菈的“国葬约定”刻在心底；最终将自己唯一的真名“菲亚”托付给她，并兑现参加婚礼的承诺。

【能力与核心战斗风格】
固有灵装：电锯型/链锯型灵装〈掠地蜈蚣〉（Ground-skimming Centipede / 地走百足）。层叠重叠锯齿刀刃如大白鲨利齿，细小锋刃如蜈蚣密足，配有机械点火拉绳与强劲轰鸣引擎，高速回旋化作钢铁风暴。
标志性起爆仪式（核心视觉与触发机制）：
1. 猛拉电锯拉绳点火：双手大力猛拉启动拉绳点火运转，引擎爆发出尖锐凄厉咆哮与宛如亡灵哀号的刺耳回转轰鸣！
2. 咬破臼齿暗藏的禁药〈天使碎尘〉：在濒死绝境中咬破臼齿内侧暗袋吞下自杀式兴奋剂，强行关闭痛觉神经，使精神集中力与身体潜能飙升数倍！
3. 轮椅踏板冲撞（后期动作习惯）：按满电动轮椅马达，以脚踏板凶狠撞击对方胫骨表达傲娇与警告；
4. 摸兜掏巧克力咀嚼：闲暇或对峙时习惯性摸出硬糖或巧克力塞进嘴里，腮帮鼓起像小仓鼠般咀嚼。
伐刀绝技体系：
1. 〈完全反射（Total Reflect）〉：概念干涉系/向量扭曲反弹。在受击瞬时于体外展开无形反弹结界，将命中自身的物理冲击、动能、斩击、子弹、魔力热量原样 100% 反弹回攻击来源，具备“敌强我愈强”特性；亦可反弹声波破坏回声定位；反向对自己施展可将自身弹射脱离险境。
2. 〈因果报应（Damage Reflect）〉：因果干涉/慢效伤害转移逆转。高于物理反射的高维绝技。将肉体承受的“创伤因果（骨折、失血、脏器破裂）”原样转移给施暴者，敌方全身喷血崩解，而多多良自身重创会在瞬间完全治愈，不留擦伤。
3. 终极神级奥义·〈星之锤（Astral force）〉：天体动力学干涉/公转伟力偏转。借用整个地球在宇宙中以时速约十万公里公转运动的超庞大动能；通过灵装将公转动能在微观上稍微偏转极微小流向倾角，溢出的庞大动能残渣瞬间化为毁灭性天体大锤！曾一击将奎多兰首都路榭尔王城、五十米高的幽狱世界树及艾茵彻底蒸发为深渊巨坑。代价是爆心边缘导致全身骨骼粉碎、肢体剥落濒死。
战斗风格机制：防守反击与绝地逆转狂战士。习惯以弱小身躯为诱饵，故意承受敌方攻击积累伤害，在对手自以为得手的瞬间发动反射或因果转移一击致命；面对无法以常理撼动的宏大对手则孤注一掷发动公转核爆。
战斗短板与致命死穴：
1. 加压盲区：反射依靠瞬时碰撞触发。面对极其缓慢逼近、逐步加压的攻击（如慢速生长藤蔓），无法捕捉动能波峰，难以形成有效反弹；
2. 瞬间意识轰碎：若遭遇超越神经反应极限的瞬间蛮力（如史黛菈一拳击碎意识），将无暇开启因果回路；
3. 星之锤反噬代价：施展后肉体承受不可逆毁灭性伤残。
