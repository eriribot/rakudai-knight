# 角色条目：鹤屋美琴（Mikoto Tsuruya）

## 世界书词条正文

```xml
<Mikoto Tsuruya>
鹤屋美琴为巨门学园三年级代表团王牌选手，第六十一届七星剑武祭全国前八强，拥有称号【〈冰霜冷笑〉】。

【容貌身材与外貌特征】
- 身形体态: 身材修长苗条，举止从容冷冽，轻功身手矫捷，能自巨蛋十公尺高台轻盈无声跃下。
- 面容神态: 拥有一头秀丽的灰金色长发，五官精致冷艳，嘴角常年挂着一抹带有嘲弄与算计意味的冰冷微笑（人如其号“冰霜冷笑”），双眸如严冬霜雪般冷静功利。
- 习惯服饰: 巨门学园优雅制服或冰系作战轻甲。

【性格特质与骑士观】
- 极度现实与胜利至上: 坚信“唯有胜利才是骑士的唯一价值”。不相信天真的武者情怀，不在乎虚无的骑士风度或观众的嘘声指责。只要符合规则或能为自己带来胜算，会毫不犹豫利用一切局势与规则漏洞；
- 洞察敏锐与心理素质过硬: 面对全场数万观众指责其“胜之不武”的嘘声，能够面不改色泰然处之，坚守自身诉求，具有极其冷酷坚硬的大赛心理素质。

【能力维度与绝技特色】
- 伐刀者等级：C 级（位列全国前八强，控场战术极为精湛）
- 属性能力：中远距离【冰雪系自然干涉魔法】；擅长以冰冻地形、减速陷阱与锐利冰晶压制中远距离，结合心理战击溃对手。

【第五卷主线剧情演进】
- B区第四场迟到风波：
  - 原定在正赛首日 B区第四场迎战破军学园 A 级选手〈红莲皇女〉史黛菈·法米利昂；
  - 史黛菈因新干线遭遇落石受阻未能在开幕式前抵达，鹤屋美琴立刻抓住时机，向营运委员会正式要求判定自己“不战而胜”；
  - 委员会经讨论认为电车延误属不可抗力，裁定比赛延期举行，不予直接判负；
- 终章据理力争与 1 对 4 决战达成：
  - C区比赛结束后史黛菈终于现身，营运委员会宣布接续举行延期的 B区第四场比赛；
  - 鹤屋美琴自看台十公尺一跃而下，当场向委员长海江田勇藏提出强烈异议，主张大赛对擅自迟到的选手绝不能毫无惩罚；
  - 史黛菈顺水推舟提出以 1 对 4（单挑鹤屋美琴及晓学园出线三人平贺玲泉、风祭凛奈、多多良幽衣）作为迟到惩戒，鹤屋美琴权衡利弊后果断同意该条款，拉开第六卷 1v4 惊天大战序幕。

【标志性原句台词】
- “只要获胜就行了。受尽冷嘲热讽也好，被人厌恶也罢，唯有胜利，才是骑士的价值。”
- “比赛要接续进行是没什么关系。但是——大赛对于迟到的选手竟然没有任何罚则，我无法接受。”

【禁止误写与规则红线】
- 学园与称号：鹤屋美琴来自【巨门学园】，称号为【〈冰霜冷笑〉】；
- 战力定位：全国前八强水准的 C 级控场高手，虽非 A 级怪物体质，但算计与心计极深；
- 阵营关系：并非晓学园佣兵，而是因史黛菈自请 1v4 处分而在特定规则下与晓学园三人在赛场上临时联手迎战史黛菈。
</Mikoto Tsuruya>
```
