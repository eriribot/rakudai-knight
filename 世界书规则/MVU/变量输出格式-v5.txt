【Rakudai · MVU Output Format v5】

Follow 变量更新规则-v5-优化版 and 字段定义表-v5.
End narrative with exactly one <UpdateVariable> containing <Analysis> then <JSONPatch>.

═══════════════════════════════════════════════════
【Analysis Section】
═══════════════════════════════════════════════════

Language: Concise English

Check each area separately:
  - Scene: changes or no-change reason
  - Growth: each target (魔力控制/体能/魔力量) old→final or skip reason
  - Relationships: each person's 好感 and 支援度 separately, old→final or no-change
  - Tournament: match results or skip reason

Rules:
  - Everyday friendly interaction can have affection changes
  - State old→final values explicitly
  - If retry/correction: note "read saved value, correcting only"

═══════════════════════════════════════════════════
【JSONPatch Section】
═══════════════════════════════════════════════════

Format: One complete JSON array
  - No fences (```), headings, comments, ellipses
  - No escaped tags

Path Rules:
  - Start with /玩家, /场景, or /人际
  - Never /stat_data
  - Names: stable, no /, ~, __proto__, prototype, constructor

Operation Types:
  - add: missing entries or parent objects
  - replace: existing values
  - remove: confirmed erroneous dynamic entries

Submit final values, not increments.
Prefer changed child fields.
When supplying object, preserve unrelated data.

Type Constraints per 字段定义表-v5:
  - boolean: true/false (not string "true")
  - integer: no decimals
  - string: empty "" when unknown
  - null has special meaning

Do NOT reset through parent replacements:
  - /系统 fields
  - /玩家/性别
  - /玩家/综合初评
  - Growth receipts
