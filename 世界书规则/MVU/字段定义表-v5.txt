【落第骑士 · MVU 字段定义表 v5】

本文档定义所有业务字段的类型、含义、更新时机和约束。
规则文档引用本表，不重复定义。

【系统字段】—— 代码维护，AI 不可覆盖
═══════════════════════════════════════════════════

/系统/结构版本
  类型: integer
  维护方: 代码
  
/系统/开局状态
  类型: string
  值域: 待建档 | 已建档
  维护方: 代码

/系统/主角模式
  类型: string
  值域: 未选择 | 一辉模式 | OC模式
  维护方: 代码

/系统/已删除人物
  类型: array of string
  含义: 随分支保存的已删除人物名单
  维护方: 代码
  约束: AI 不得重建其中人物

/系统/关系计分
  类型: object
  含义: 本回复关系收据（防重用）
  维护方: 代码
  约束: AI 不写入此字段

【场景字段】
═══════════════════════════════════════════════════

/场景/当前卷
  类型: integer
  值域: 1-19
  含义: 当前所在卷号
  更新: 实际进入新卷时

/场景/当前章
  类型: string
  含义: 注入目录的稳定键（非章节标题）
  更新: 完成当前章且明确进入下一章时
  约束: 本轮最多前进一个节点

/场景/阶段
  类型: string
  值域: 未开始 | 进行中 | 已结束
  含义: 当前章节的进度状态
  更新: 按完成标识判断

/场景/时间
  类型: string
  含义: 当前场景时间
  格式: 自由文本（如"4月15日上午"）或 YYYY-MM-DD
  约束: 未知时保持空字符串，不编造

/场景/地点
  类型: string
  含义: 当前场景地点
  约束: 未知时保持空字符串

/场景/切入说明
  类型: string
  含义: 场景切入的简要说明

/场景/已发生事件
  类型: object
  键: 稳定事件名称
  值: {
    卷号: integer,
    章段: string,
    结果: string (非空),
    参与者: string[],
    知情者: string[]
  }
  约束: 
    - 只记已发生结果
    - 归属推进前的章节
    - 不写未来章节
    - 不把不知情者列入

/场景/日程
  类型: object (可选)
  键: 稳定日程名称
  值: {
    类型: string (比赛|训练|约定|其他),
    日期: string (YYYY-MM-DD 或空),
    时间: string,
    地点: string,
    参与者: string[],
    状态: string (待定|已安排|进行中|已完成|已取消),
    说明: string
  }
  约束:
    - 只记已知安排
    - 日期未知时留空
    - 实际开始/完成再改状态

【玩家 - 觉醒与能力】
═══════════════════════════════════════════════════

/玩家/魔人觉醒
  类型: boolean
  值域: true | false (原生布尔，非字符串)
  含义: 本局是否已确认魔人觉醒
  更新时机: 本轮明确觉醒时设 true
  影响:
    - true: 魔力控制/体能/魔力量均可获新成长
    - false: 魔力控制/体能可成长，魔力量只可纠错旧值
  约束:
    - 觉醒本身不赠送经验
    - 误记可按事实纠正
    - 无并行境界标志

/玩家/伐刀能力
  类型: object
  子字段:
    能力系别: string (空 | 体能强化系 | 自然干涉系 | 概念干涉系 | 因果干涉系)
    能力本质: string
    共通限制: string
    招式: object

/玩家/伐刀能力/招式
  类型: object
  键: 招式名称（稳定）
  值: {
    说明: string,
    条件与代价: string,
    掌握状态: string (待确认|学习中|已掌握)
  }
  约束: 按实际学习/应用结果更新，描述自由

/玩家/其他能力
  类型: object
  键: 能力名称（稳定）
  值: {
    说明: string,
    条件与代价: string,
    掌握状态: string (待确认|学习中|已掌握)
  }
  含义: 剑术/体术/分析/生活技艺等

【玩家 - 成长系统】
═══════════════════════════════════════════════════

/玩家/成长/经验/<目标>
  类型: integer (非负)
  目标: 魔力控制 | 体能 | 魔力量
  含义: 当前档位内的成长进度
  更新方式: 主副API直接提交终值
  成长条件:
    - 实际练习/应用/改良/突破
    - 体能需身体实际参与，纯想象不算
    - 魔力量新成长需觉醒=true
  约束:
    - 读已保存值，只补漏或纠错
    - 同一成果在同一reply只计一次
    - 历史回忆/跳章不补造训练

晋级计算:
  门槛表:
    F  → F+: 100   | F+ → E:  100  | E  → E+: 150  | E+ → D:  150
    D  → D+: 250   | D+ → C:  250  | C  → C+: 400  | C+ → B:  400
    B  → B+: 600   | B+ → A:  900  | A  → A+: 1200 | A+ → S:  1600
  
  晋级规则:
    - 达到门槛连续晋级
    - 逐档扣除门槛并保留余量
    - S为顶档，保留余量
    - 提交最终档位和余量

/玩家/六维/<维度>
  类型: string
  维度: 攻击力 | 防御力 | 魔力量 | 魔力控制 | 体能 | 运气
  值域: F | F+ | E | E+ | D | D+ | C | C+ | B | B+ | A | A+ | S | ""
  含义: 实际能力档位
  约束:
    - 空字符串表示未确认
    - 随经验晋级更新
    - 永久成长/评级纠错可改
    - 临时强化/疲劳写在描述中

/玩家/登记等级
  类型: string | null
  值域: F | F+ | E | E+ | D | D+ | C | C+ | B | B+ | A | A+ | null
  含义: 学园正式登记等级（非实际战力）
  更新: 实际发生登记/重评时
  约束: 不随经验自动改变

/玩家/综合初评
  类型: object
  维护方: 代码/初评系统
  约束: AI 不可覆盖此对象

/玩家/成长/<历史字段>
  维护方: 代码
  约束: AI 不创建或覆盖成长申请、版本、收据

【人际字段】
═══════════════════════════════════════════════════

/人际/<姓名>
  类型: object
  键: 人物姓名（稳定，不含特殊字符）
  约束: 不重建 /系统/已删除人物 中的姓名

必需字段:

/人际/<姓名>/关系
  类型: string
  含义: 与玩家的关系定位
  示例: 同学、导师、对手、队友

/人际/<姓名>/态度印象
  类型: string
  含义: 对玩家的态度和印象描述

/人际/<姓名>/好感
  类型: number | null
  值域: 0-1000 或 null
  含义: 对玩家的态度倾向
  更新:
    - 有态度变化就及时更新
    - 普通友善对话可有变化，不需重大事件
    - 独立于支援度
  参考增量（非硬性规则）:
    - 普通友善回应: +2~10
    - 认可/防备缓和: +11~20
    - 重大关系改变: +21~40
    - 负向变化按实际影响核定
  null含义: 待核定（可在事实明确时修正）

/人际/<姓名>/支援度
  类型: integer | null
  值域: 0-320 或 null
  含义: 落实的支持、协作和信任
  更新:
    - 需要实际行动
    - 独立于好感
    - 许诺不自动增加
  参考增量:
    - 日常协作: +1~5
    - 克服阻碍: +6~10
    - 重大协作: +10~15
  null含义: 待核定

/人际/<姓名>/羁绊阶段
  类型: string
  值域: 未定 | 未建立 | C | B | A | S
  维护方: 代码派生
  派生规则:
    0-79: 未建立
    80-159: C
    160-239: B
    240-319: A
    320: S
  约束: AI 不直接写入，由支援度自动派生

/人际/<姓名>/变化依据
  类型: string
  含义: 本次好感/支援变化的简要依据
  格式: 简记关键事实 + 旧值→新值
  约束: 不要求固定格式或关键词

可选字段:

/人际/<姓名>/性别
  类型: string
  值域: 未知 | 男性 | 女性

/人际/<姓名>/联系状态
  类型: string
  值域: 仅识别 | 已建立联系
  含义: 首次双向言语或行动即建立联系

/人际/<姓名>/联系依据
  类型: string
  含义: 建立联系的简要说明

/人际/<姓名>/已加联系方式
  类型: boolean
  含义: 是否已交换联系方式（独立于面对面交流）

/人际/<姓名>/已知资料
  类型: object
  可选子字段:
    身份: string
    登记等级: string
    灵装: string
    已知能力: string

/人际/<姓名>/恋爱阶段
  类型: string (代码派生，AI不可见)
  派生条件: 已确认女性 且 好感有效值
  派生规则:
    0-199: 路人
    200-499: 在意
    500-799: 暧昧
    800-999: 交往
    1000: 生死相随
  约束: 不倒补未发生的告白/婚约/亲密经历

/人际/<姓名>/名册隐藏
  维护方: 代码/终端
  约束: AI 不写入

【选拔赛字段 T02】
═══════════════════════════════════════════════════

/场景/选拔赛
  类型: object (可选，不参赛可不存在)

/场景/选拔赛/版本
  类型: string
  值域: T01 | T02
  默认: T01

/场景/选拔赛/赛季
  类型: string
  默认: 破军学园选拔赛

/场景/选拔赛/状态
  类型: string
  值域: 未开始 | 进行中 | 已结束
  
/场景/选拔赛/总轮次
  类型: integer
  默认: 20

/场景/选拔赛/代表名额
  类型: integer
  默认: 6

/场景/选拔赛/号池规模
  类型: integer
  默认: 288

/场景/选拔赛/模式
  类型: string
  默认: 跟随系统
  约束: 不向AI开放，始终跟随主角模式

/场景/选拔赛/名册/<ID>
  类型: object
  键: 稳定参赛者ID
  值: {
    姓名: string,
    来源: string (正典|原创|玩家),
    参赛状态: string (参赛|退选|取消资格),
    入赛轮次?: integer (1-20)
  }
  约束:
    - 入赛轮次只能由终端人工纠错
    - 来源=玩家 由系统模式和玩家姓名确定
    - 保留历史 初始战绩 但AI不创建/修改

/场景/选拔赛/比赛/<ID>
  类型: object
  键: 稳定比赛ID
  值: {
    轮次: integer (1-20),
    甲方: string (rosterID),
    乙方: string (rosterID),
    日期: string,
    时间: string,
    地点: string,
    状态: string (待定|已安排|已完成|已取消),
    胜者?: string (rosterID),
    弃权方?: string (rosterID),
    依据: string
  }
  约束:
    - 每轮每人至多一场
    - 同一对手组合不重复
    - 已完成需有实际胜者和依据
    - AI 只写实际比赛，不写积分/排名

AI 禁止写入:
  - 甲赛前胜场
  - 乙赛前胜场
  - 初始战绩
  - 积分
  - 排名
  - 程序战况
  - __rk_bg_ 开头的ID

/场景/选拔赛/一辉拘押
  类型: boolean (可选)
  含义: 一辉实际发生拘押时置true，启用R17-19延赛

/场景/选拔赛/退赛日期
/场景/选拔赛/结束日期
  维护方: 代码
  约束: AI 不写入

/场景/选拔赛/程序战况
  维护方: 程序
  约束: 只读摘要，AI不写入
