## 行为与变更边界

目标：真实主保存完成后及时进入校正；主补丁缺失或损坏可由副 API 全面修复；原生对象型补丁的确定性路径错误可以自动适配。自动开关仍控制全面自动校验，关闭时保留手动预览与应用。

分三个局部修复阶段，非重写：

1. 保存确认：真实主解析的同一变量对象携带唯一收据，随 delta_data 写入当前消息槽；回读同收据与业务值才解除写锁。每轮用 eventMakeLast 将同一收据尾监听移至 Zod 尾处理之后，防止桥接清除包装后漏收据。渲染只唤醒核验，不作为保存证据。同楼同补丁续写仍需新收据并重新全面核验；迟到事件恢复原任务，但取消后不会擅自重开。
2. 修复来源：MVU02 将真实聊天、消息对象、楼层、swipe 和来源内容绑定，与主补丁合法性分离；缺块、截断或多块可修复。解析前后及写入前均重验来源与真实变量，保留同轮关系/成长收据。普通主来源识别未放宽为任意文本。
3. 主补丁与效率：N04 在 COMMAND_PARSED 后、Zod 前归一确定的对象型 add/replace；缺父记录用本批明确内容一次构造，replace 不存在字段转 add。不猜必填事实，不覆盖坏父类型，不改混合删除、数组或已有容器替换的原生语义。副补丁接受单层代码围栏或完整标签外壳，但不猜补截断内容。

效率变化：省去副补丁第二次归一化、重复快照深拷贝与应用前重复读取；只在请求副本去掉重复的程序战况，仍保留全部真实业务字段与独立程序摘要。120 秒超时停止自动重试，仍可手动重试；临时网络错误保留有限退避。实测构造样例的用户 JSON 少 1,551 字符，不能据此宣称真实响应提速百分比。

红线：不改主连接、密钥作用域、业务权限、成长规则、初始化或世界书文本；不覆盖历史聊天；不凭超时抢主写；不将缺失字段的事实凭空补齐。已有首楼辅助请求隔离保持。
