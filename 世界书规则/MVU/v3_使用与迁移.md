# 第一卷校准 · MVU v3 使用与迁移

2026-09-07，修订 3.1.0。范围仍为第一卷，以第一章为首批原文依据。开局人格文案、R05 公式与 C/B/A/S 玩法方向保留。

## 修复与导入

截图中的分数 5.333333333333333 本身合法。MVU 在更新前把临时 $internal（display_data、delta_data）放进 stat_data，旧 strict 根对象误拒此字段，连合法补丁也失败。新版仅豁免根层 $internal 的业务校验并原样保留，由 MVU 在结束事件后移除；其他业务字段仍 strict。玩家无需手动删除它。

1. 更新[完整世界书](../v0.3/导出/落第骑士英雄谭.json)及卡片使用的[开局页](../../第一卷-世界书整理/开局页面/index.html)。磁盘文件修改不会自动覆盖已导入角色卡。
2. 导入[新版字段约束脚本](落第骑士-MVU-v3字段约束.json)，以相同 ID 替换旧版，勿同时启用两个版本。世界书 JSON 不会自动安装脚本。
3. 启用 MVU 和伴随脚本，看到“已注册字段与第一卷范围约束（3.1.0…）”日志后再新建 v3 聊天。等待 MVU 超过 15 秒会报错；启用框架后重新启用伴随脚本。注册不会重放已发出的初始化事件。
4. 填写档案、章段、时间、地点及切入说明，核对开场白后点击建档。时间可用“春假早晨”等相对表达。
5. 代码写入并回读成功后提供第一幕请求。玩家手动复制发送即可续写，模型不重复初始化，也不再强制空耗一轮建档。页面不会自动发送消息。
6. 可选导入[轮盘终端 v1.3.0](../../scripts/酒馆助手脚本-小手机-黑白ADV轮盘版-v1.3.0.json)，替换旧版终端，查看状态并确认章段。

本次没有自动导入酒馆、修改真实聊天、提交或推送 Git。原世界书快照位于 output/worldbook-calibration/落第骑士英雄谭-修改前.json。

## 写入分工与状态

| 字段 | 写入方 |
|---|---|
| 系统、首次玩家档案与选定场景 | 开局页代码，待建档分支只能应用一次 |
| 玩家.综合初评 | 页面计算结果，正文不重算 |
| 场景.当前卷、当前章、阶段、切入说明 | 共享控制器，第一卷固定 |
| 实际时间地点、能力成长、事件、人际、剧情确认的登记等级 | 模型按世界书规则更新 |
| $internal、display_data、delta_data | MVU 框架维护，不作人物设定 |

伴随脚本在更新结束事件保护代码管理的字段，父对象替换也不能绕过。待建档时模型不能代页面初始化；因此旧版“请将开局 JSON 写入变量”的消息不是新版建档入口，应使用页面按钮。恢复章段后若关联新事件超前，保护器回退该次业务更新并提示。

控制器捕获聊天、最新助手楼层、活动 swipe、消息文本及完整变量快照；同步 updater 回调内再次核验，保留事件、人际与其他 MVU 包装字段。已有场景与草稿冲突时拒绝覆盖；历史开局页不能修改后续助手楼层。

重复点击只写一次；原凭据仅能重试相同操作。若写入已落地但响应异常，重试先比较结果，不再次初始化。切聊天、swipe、编辑消息、新增楼层或其他变量变化会使旧操作失效。已建档后编辑草稿不覆盖角色；页面重载丢失内存回执也不解除建档限制，可继续已有聊天。

终端按“确认结束 → 下一章（未开始）→ 开始”转换，终章结束仍停第一卷。按钮表示玩家确认；代码只检查操作次序，不能证明事件已经发生，不按轮数强制胜负、恋爱或觉醒。

## 字段与档案版本

| v2 路径 | v3 路径或行为 |
|---|---|
| 系统.结构版本 = 2 | 3；模式为未选择／黑铁一辉／自定义角色 |
| 场景.当前卷 | 严格为数字 1；新增当前章、阶段、已发生事件 |
| — | 场景.切入说明记录开局上下文；旧 v3 缺失时补空串 |
| 玩家.伐刀绝技 | 玩家.伐刀能力.招式，按名称记录多项或空集合 |
| 玩家.能力系别／能力机制／限制与代价 | 玩家.伐刀能力.能力系别／能力本质／共通限制 |
| — | 玩家.其他能力，记录剑术、体术与其他技艺 |
| 旧人际阶段文字 | 留在变化依据，不擅自折算 C/B/A/S |

固定对象 strict，招式、事件、人际允许有名条目。未知不转成 0 或 F，不引入未确认 HP/MP/AP/SP；一辉魔力量“平均值十分之一”不等于原作 10 MP。自定义角色登记等级初始 null，一辉 F。

页面档案升 v5，兼容旧 v2/v3/v4；与 MVU 结构 v3 是不同版本。旧档新增场景、本局状态补充默认空。能力每行“名称｜说明｜条件与代价”，只写名称也可，允许空集合；旧组合名称不猜测拆分。页面明确将填写项目记作已掌握。

通用提示词区分既往经历、当前身体、当前可用能力及玩家明确采用的本局换算；补充内容以小标题写入既有玩家.角色简介。不硬编码示例角色，不把跨界境界自动换成魔人。开场白生成读取结构化场景；玩家核对正文一致，代码不声称能判断任意自然语言地点描述。

## 依赖与已核接口

- 宿主：SillyTavern；控制器要求 Tavern Helper 至少 4.8.19 的同步变量接口、消息读取与 Zod 4。目标电脑具体版本未识别，本次没有升级。
- 卡内：MVU 需已启用；本卡 schema 和共享控制器内嵌在交付文件，不用 localStorage 另存剧情状态，不引入另一套数据库。
- 远程：registerMvuSchema 通过 testingcf.jsdelivr.net 加载固定提交，非离线资源；其传递依赖没有全部固定。
- ST-Prompt-Template/EJS 是现有条件模板的依赖；实际上下文与两种身份仍需实机验证。旧正则 EJS 拦截脚本本次未改，不能视为完整模板引擎。
- 开发：output/worldbook-calibration/dev 下 zod 4.1.12、yaml 2.8.1、ejs 3.1.10；终端 DOM smoke 另有开发依赖。这不是玩家安装 npm 的要求。

固定证据：[TH 变量实现](https://github.com/N0VI028/JS-Slash-Runner/blob/36d8889a99f1cf09d3d1f8aabd0eba33975dc64d/src/function/variables.ts)、[消息声明](https://github.com/N0VI028/JS-Slash-Runner/blob/36d8889a99f1cf09d3d1f8aabd0eba33975dc64d/@types/function/chat_message.d.ts)、[MVU 全局实现](https://github.com/MagicalAstrogy/MagVarUpdate/blob/b42817925d0391c15fa242a8238d2bbe28eb6319/src/function/global/index.ts)、[MVU 更新生命周期](https://github.com/MagicalAstrogy/MagVarUpdate/blob/b42817925d0391c15fa242a8238d2bbe28eb6319/src/function/update_variables.ts)、[Zod 桥接器](https://github.com/StageDog/tavern_resource/blob/dee97e8c3e24e1e75efe21141743e4b5c0af776e/util/mvu_zod.ts)、[ST 上下文](https://github.com/SillyTavern/SillyTavern/blob/8172dcd0ee672d3cd9a5e5f7af134f91a45cd2b8/public/scripts/st-context.js)。

同步 updateVariablesWith 在回调返回后立即赋值并安排保存。VariableOption 没有独立 swipe 参数，所以控制器用 include_swipes:true 读取并复核活动 swipe。回读只证明宿主内存已更新，服务器保存及重载持久化须实机确认。registerVariableSchema 只是编辑器 UI，不代替更新保护。桥接器按命令校验，前一条成功不因后一条失败回滚；其对直接 ZodObject 会改用 looseObject，本卡以 preprocess 保留业务 strict。

## 迁移、构建与验收

修改 InitVar 不迁移旧聊天。旧聊天先备份，导出单独 stat_data：

```powershell
node scripts/migrate-worldbook-state.mjs --input output/旧stat_data.json
node scripts/migrate-worldbook-state.mjs --input output/旧stat_data.json --out output/新stat_data-v3.json
```

前者只验证，后者只新建候选文件，不连接酒馆、不覆盖原件。迁移保留已填值、场景、人际数值；旧组合招式保留一项并标待确认，未知关系原文保留。未知字段、第二卷数据、非法系别或未知版本明确拒绝；v3 重复迁移幂等。确认候选后仍须在正确楼层与 swipe 处理 MVU 状态，不能只改显示缓存。

```powershell
node scripts/build-state-controller.mjs --write --page
node scripts/sync-worldbook-calibration.mjs --write
node scripts/黑白ADV轮盘终端/build.js

node scripts/build-state-controller.mjs --page
node scripts/sync-worldbook-calibration.mjs --check
node scripts/check-worldbook-calibration.mjs
node scripts/check-mvu-runtime-schema.mjs
node scripts/check-state-controller.mjs
node scripts/check-state-browser.mjs
node output/check-opening-controller.cjs
node scripts/黑白ADV轮盘终端/smoke-test.mjs
```

当前离线结果：校准 70 项、元数据 11 项、状态控制 13 项、宿主适配模拟 12 项、开局页交互契约 25 项；报告见 output/worldbook-calibration/。终端 DOM smoke 见其目录。按对应 package-lock 恢复开发依赖。

真实宿主待验：新版脚本启用、新聊天初始化、建档后 EJS 两种身份、合法与非法补丁、终端章段操作、编辑/swipe/切聊天/重载隔离与持久化。本地浏览器预览此前被 URL 安全策略阻止，没有换浏览器或地址绕过。交付状态为“本地文件与离线验证完成，真实酒馆启用待验证”。

技能收据：TavernWeave 导航快照 2026-08-18；API、数据模型、嵌入 UI、组件更新技能，已读 A0/C4/C7。未引入其他数据库或实验性同层方案。执行授权来自用户“边界清楚了可以去动工”。
