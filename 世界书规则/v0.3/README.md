# v0.3 世界书规则作者源

本轮落实 U 建档、六维参照、综合初评与能力复核。用户于 2026-09-05 表示可以开工。这里是可逐条复制的世界书正文与设置建议，不是已导入酒馆的发布包。

与 `第一卷-世界书整理/人物条目` 并用：人物资料负责对应时期的事实，本目录负责本卡玩法与判定。后卷人物表只用于作者校准，不将其后续事件写成开局已发生的历史。

使用方法：新建条目，将文件中 `<!-- 正文开始 -->` 与 `<!-- 正文结束 -->` 之间的文字放进正文。标题、触发建议、来源和本文都不注入。第一版建档期间可直接启用 LK-U/AXIS/RANK，别只依赖某个关键词一定会触发。运行中若使用 EJS 条件选择，由它只读取当前状态决定是否提供内容，不执行结算。

维护入口：开局页内 `opening-rating-engine` 脚本保存确定性公式和六维参照；`node scripts/check-opening-rating.cjs --sync-anchors` 只同步本目录 02 的正文。无参数只读检查公式样本和同步状态。没有依赖安装、角色卡打包、自动部署或远程写入。

建档页面目前通过复制请求、贴回评定 JSON 与 AI 配合。实际酒馆/MVU/EJS 版本尚未识别，因此这轮不冒充已接通自动发送、消息落楼或 MVU 初始化。`变量接线契约.md` 是后续连接约束，不是 AI 可直接执行的补丁协议。

已实现的验收入口：四项完整时显示初评；粘贴对应档案的有效评定后显示拟定登记级；预览、JSON、槽位与 PNG 保持一致。真实宿主验收另列于开局页 `validation.md`。

工程收据：TavernWeave 快照 2026-08-18；路由 `sillytavern-card-pipeline`，读取 A0/A2/D1/D4 与 API 权限边界。范围是源文件迭代；沿用原生浏览器和既有远程媒体，没有新增远程运行库。用户的开工授权覆盖本轮可逆源修改，不重复请求技能中的方向确认。
