# LK-RANK-001 · 综合初评与复核

启用建议：与六维参照一起启用。关键词参考：U档案评级 R05、综合初评、评级复核、能力评定。

【综合初评与复核 R05】
这是本卡原创 U 的初评算法 r05-v1，不是原作公开的评级制度。

1. A=6、B=5、C=4、D=3、E=2、F=1；B+ 至 F+ 分别在本档加 0.5；A 为本次上界。中间档需要额外依据，不因四舍五入便利而滥用。
2. 取攻击力、防御力、魔力量、魔力控制四项，去掉一个最低值，将其余三项相加除以 3。并列最低时只去掉其中一项。
3. 对平均分四舍五入，.5 向较高整数取整，再转换为 A—F 初评。体能与运气不参与计算。未知项不能当最低值丢弃，四项不齐就暂不出初评。
4. 能力复核默认维持。仅当六维与平均公式遗漏了重要的能力用途、可靠性或严重限制时，才允许相对初评上调或下调一级；必须写出具体理由。总级仍限于 F—A。
5. 已计入攻击等维度的强项，不重复奖励。不能套用“攻击 B 就升一级”“有初见杀就升一级”“无攻击就降一级”“体能 F 就降一级”的自动规则。特殊机制必须同时考虑发动条件、反制方式、覆盖、持续性与代价。
6. 复核不足以容纳某种极端能力时，标记需要进一步讨论，不叠加多个 ±1、不把多个回合的复核累加升级。每次均从当前六维重新计算。

保留六维依据、计算初评、拟定登记级、调整幅度与复核理由。能力描述、限制或六维变更后，旧复核失效，应重新审查。晋级不自动补满当前魔力，也不扩大先天上限。

参照：珠雫 D/B/C/A 去最低后为 5，初评 B；一辉 F/F/F/E 为 1.333，初评 F。原作兔丸 C 和泡沫 D 并不能由这套公式直接还原；原作人物保留原等级，不捏造联盟的升降理由。
