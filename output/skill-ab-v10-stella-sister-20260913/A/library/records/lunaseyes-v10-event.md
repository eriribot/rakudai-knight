# 露娜艾丝：试探、战争条件与公开誓约

她想见识史黛菈带来的男人有多少斤两，因此装作没发现父王企图，同时预备国营广播以备援助。一辉闯入她更衣的房间后，她将他拖入屋内，确认无人察觉再关窗拉帘。

她给一辉出的题目是作为法米利昂代表参加与奎多兰的战争：赢过自己的敌人，而且为法米利昂带来胜利，只有个人获胜不够。两国依联盟条约以魔法骑士代表决斗处理纷争，不动用普通兵器与军队；每五年争夺一次国境天然气田所有权。今年五名代表各比一场，以胜场较多者获胜。

她指出法米利昂最近三十年没有赢过；改变这一局面就能直接贡献国家利益，让包括父王在内的人无法再反对婚约。据约翰转述，她似乎从一个月前便不断亲自交涉，用战争考验一辉是否适合成为史黛菈夫婿；奎多兰国王已准许一辉特别征召参战。

她预先准备的麦克风连接皇都所有广播设备，家庭会议对话通过国营广播传出。她取得席琉斯首肯，又当着国民宣告：国王以战争胜利为前提认可一辉成为史黛菈夫婿，国民表示支持。一辉已接受题目、承诺带来胜利；尚不能写成条件已履行。
