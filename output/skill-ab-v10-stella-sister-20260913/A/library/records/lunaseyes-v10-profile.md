# 露娜艾丝：身份、外貌与工作

露娜艾丝·法米利昂是史黛菈的姐姐、法米利昂皇国第一皇女、下任女王，尚未继位。家人称她露娜，史黛菈称她露娜姊。父亲是席琉斯，母后是阿斯特蕾亚，妹妹史黛菈是第二皇女。

淡淡的桃色秀发、鲜红双眸，容貌富有知性美；胸部小巧。初次遇见一辉时正在更衣，只穿蕾丝内衣，不能将这一幕当作固定日常装束。
