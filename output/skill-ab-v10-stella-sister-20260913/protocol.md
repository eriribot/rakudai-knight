# 第十卷：史黛菈姐姐世界书 A/B 实验

用户任务：两个 skill 在小说第十卷找史黛菈的姐姐，制作世界书并对比。

## 固定条件

- 同一宿主、同一继承模型设置、两个不继承争论历史的独立子 Agent；每个技能只运行一次。不是统计显著性研究。
- A 使用 TavernWeave v1.6.0 / build-work-library，固定源码提交 612c51980549e179bb73ead699aa1c37680db08e。
- B 使用用户本地 character-visual-lore-dossier 的冻结副本，正文和附件不修改。
- 唯一事实材料为 inputs/volume10.utf8.txt；inputs/volume10.numbered.txt 是同行号副本。保留原文措辞与原有错误，仅做无损解码和 LF 换行规范化。
- 两组均需自行从“史黛菈的姐姐”定位身份，不预先提供姓名、事实答案或另一组的检索结果。
- 禁止联网补设定、读取其他卷、旧资料库、既有世界书内容、对方结果或裁判答案。技能自带案例可读，但不能把与任务无关的角色案例当本卷事实。
- 使用真实原生工具读取材料。不得另开子 Agent。两组允许各自内部自检；提交后冻结首轮结果，不根据裁判反馈重写参赛版本。
- 共用 JSON 字段模板从项目现有导出提取并清空文本；避免用不同导出格式影响内容比较。没有宣称这个模板已通过当前酒馆导入。
- 执行成本只报告可观察的文件体量、步骤和耗时；无法实测 token 就标不可见，不估造节省比例。

## 共同交付

面向小说第十卷结束时的知识范围，为史黛菈的姐姐制作可供角色扮演模型使用的世界书。以本卷实际支持的身份、外貌、性格与说话方式、人物关系、动机与行为为内容。可分 1–4 个职责明确的条目，正文总量不超过 3500 中文字符左右；不要求为了填满栏目补设定。

每组输出到自己的 A/ 或 B/ 目录：

1. worldbook.md：方便人直接阅读的最终世界书正文，区分条目和触发词。
2. worldbook.json：顶层为 entries 对象；条目键与 uid 一致；从 inputs/entry-template.json 复制字段，再填写自身内容。正文不塞开发过程或实验评论。
3. evidence.json：列出最终正文可核对的事实。每项包含 id、claim、line_start、line_end、quote、status（direct/inference/uncertain）以及对应 entry_uid。quote 是原文中连续出现的短摘录，行号基于共同输入；如果一个结论需要多处证据可加 evidence 数组。
4. process.md：实际读过的技能/参考文件、执行步骤、无法核实或未覆盖内容、最终自检情况。可以附加各自技能要求的资料库文件。

A 属于首次单角色小样本：按技能允许的人工少量 Markdown 条目并 reindex 路线执行即可；不必为了单角色强建长任务批次。实际运行了什么据实记录。

## A0 / 写入范围回执

- 目标：两份第十卷同人物世界书及逐项核对结果。
- 红线：原小说、已安装技能、现有世界书和对方实验目录不改；不安装、不上传、不推送、不接入实际酒馆。
- 写入：已获用户“去做 A/B 对比试验”授权。只在本实验输出目录保存输入副本、技能快照、各组产物和报告；无需重复请求许可。
- 验收：实际世界书与原文逐项对照；结构校验与语义复核分别报告；未做真实酒馆导入就明确写未验证。

## 预先固定的判定方法

- 优先检查人物是否找对；再检查无依据补写、原文矛盾、推断冒充事实、引用错配和跨阶段混用。
- 关键内容覆盖表由独立裁判仅阅读原文后建立，并在查看两组输出前冻结。只把与此人物制卡实质相关的事实列为覆盖点。
- 对双方的每条正文都检查；证据表不全不能让正文中的无来源断言逃过审查。
- 引文逐字存在只算引用校验通过，不等于支持解释。引用真实性、语义忠实性、覆盖度和世界书可用性分别评定，不拿文档数量代替质量。
- 明确区分“原文直接陈述”“合理但需要标注的推断”“本卷无法确认”；不把缺少原文证据直接等同于反证。
- 保留首轮原始产物。错误修订如有必要另存，不覆盖本次比较证据。
