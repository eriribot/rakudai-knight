本轮读取的是实际安装的 `落第x学战v0.02.png`，宿主 SillyTavern 1.19.0。旧 v0.01 文件已不存在，没有沿用旧身份或哈希。

气泡缺失发生在姓名匹配前：当前已落盘的助手第 2 楼正文有 119 个双语段，独占行的“姓名:台词”为 0 条。目标中文对白直接以引号起头，日文原文也没有明确说话人前缀。完整消息经当前三条气泡规则仍为 0 个气泡；只在内存给其中一条中文对白补上明确的 `克劳蒂雅:` 后，该条生成 1 个气泡。没有改动聊天文件。

当前角色已允许局部正则；气泡 01、02、03 均启用，排列正确，查找与替换内容均等于维护源码及发布产物。不是头像清单未部署，也没有进入“已有气泡节点但 CSS 没生效”的阶段。

当前咩咩预设的“中日双语”提示词已启用，其示例是匿名引号译文；世界书 uid43“聊天气泡规则”虽常驻启用并要求姓名前缀，却未明确双语时中文行也要带姓名。两条“双语美化”显示正则均已关闭，未在本次现场删除姓名。提示词存在格式冲突的证据；未抓取本次完整生成请求，不能宣称已证明具体模型取舍过程。

维护源 `scripts/正文气泡/format-rule.txt` 现明确：日文保留 `☆‹›`，中文对白独立写成 `姓名:台词`，旁白、动作、招牌与驱动块不加说话人。发布文本、预览及来源收据由现有构建同步；三条正则、CSS 和构建 spec 保持原字节。没有从匿名对白猜测人物，也没有修改玩家预设。

手动替换文件为上级目录的 `worldbook-uid43-聊天气泡规则.txt`，只供替换目标世界书 uid43（标题“聊天气泡规则”）的内容字段；其他条目及该条目的启用、位置、深度、顺序等设置保持原值。这不是整本世界书或角色卡包，未自动写入真实世界书。

原条目的规则要求全部保留。旧示例 `{{user}}:我先去训练场。` 使用维护源已有的 `玩家:我先去训练场。`，符合原规则“玩家优先固定写玩家”的约定；其余旧例保留。若后续模型仍照预设输出匿名引号，可选在自己的预设副本里将中文对白示例改成 `克劳蒂雅:「……那个啊」`，上行 `☆‹「……あのさ」›` 保持原样。无需先改预设才能使用本规则；本轮未改预设，也不承诺模型每轮必然遵守。

回归使用本机实际 `engine.js` 和 `regexFromString`，在隔离 Node VM 中运行中性 fixture。仅用户宏使用固定测试值；没有运行预设中的脚本、Markdown 或浏览器。
