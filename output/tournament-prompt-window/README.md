# 号池提示日期门禁 · v1.3.27

只替换小手机脚本即可。世界书的原条目、order、结构和变量列表正文保留，不需要指定 UID 或替换世界书条目。

门禁读取当前活动回复页 MVU `/场景/时间`，沿用赛程配置的 **2013-04-22 至 2013-07-08（含首尾）**。范围内且赛季未结束时放行程序号池提示；范围外、日期不明确或赛季已结束时拦截。

主请求在世界书模板展开后、请求发送前，仅从原变量列表的发送副本省略 `/场景/选拔赛/程序战况`。消息位置、前后文字、真实名册和比赛保持。副 API 继续读取真实账本，独立的程序选拔赛摘要按同一日期条件发送。

原 MVU 的缓存和历史不改写。最新回复尚无 MVU 时不借用上一楼层的日期放行；正常生成期间，同一活动回复页的已保存日期仍可使用。

## 使用

用 `components/helper/terminal.script.json` 或 `世界书规则/MVU/落第骑士-小手机-v1.3.27.json` 替换同 ID 的旧终端脚本，保留一个启用实例并重新载入。当前预览已重建。

门禁随终端脚本启用，收起终端窗口仍有效；停用整个脚本则门禁不运行。依赖现有 Tavern Helper 的 `eventMakeLast`、`eventRemoveListener` 和 `CHAT_COMPLETION_SETTINGS_READY`，在模板展开 JSON 后运行。此交付验证 Chat Completion 请求；真实酒馆的模板执行先后仍需实机验收。

可观察的验收信号：4 月 21 日发送的变量列表没有程序战况；4 月 22 日允许；7 月 8 日允许；7 月 9 日省略。四种情况下真实比赛和名册都还在。
