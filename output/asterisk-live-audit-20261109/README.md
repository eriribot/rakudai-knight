# 学战剧情注入只读核对 · 2026-11-09

## 结论

当前酒馆可以读取学战剧情，但不能正确处理第一卷终章到第二卷第一章。现有目录会把第二卷第一章误读为第一卷终章，之后停止推进。关闭剧情条目自动触发的设置是正确的。

## 实机与落盘证据

- 酒馆当前卡绑定 `落第x学战v0.03` 世界书，共 241 条；当前聊天仍在开局阶段。
- 实际安装注入器 revision 为 `20261104.1`。代码副本：[installed-injector.js](./installed-injector.js)。
- 世界书第一卷到第七章《解放者》（order 207），缺少第一卷终章条目。
- order 208 实际是 `[剧情]第二卷.第一章.六花园会议`（UID 226），但注入器将 208 视为第一卷终章。
- 第二卷已有第一章至第七章及终章《蜀山组队》，order 208–215。条目元数据：[installed-plot-metadata.json](./installed-plot-metadata.json)。
- 本地交付版 `20261107.1` 也只收录学战第一卷；仅替换成这个版本不能修复跨卷。
- 学战 MVU 目前将 `场景.当前卷` 和事件 `卷号` 限制为 null（`世界书规则/MVU/schema.mjs:343–352`），终端校正提示词也要求保持 null（`scripts/黑白ADV轮盘终端/correction.js:539`）。因此不能通过手动改成卷 2 来解决。

## 原因与修复边界

`rakudai-story-catalog.mjs` 学战目录只有第一卷，`rakudai-plot-runtime.js` 的学战卷号固定为 1。读取器按 `[剧情]` 前缀与 order 取条目，未验证标题是否对应期待卷章。

需同步：补回第一卷终章；扩充学战卷章目录；支持学战卷号及事件卷号并兼容旧档；同步终端与校正规则；校验条目卷章与目录一致，避免静默读错。第二卷导航注明序幕仅简介、不设场景，因此第一卷终章应直接衔接第二卷第一章。
