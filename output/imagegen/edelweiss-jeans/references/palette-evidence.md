`vol12-colored-title.jpg` 和 `vol12-edelweiss-head-detail.png` 来自本地 EPUB 彩色标题页，与官方封面是同一插画，不能算两张独立设计证据。

`edelweiss-avatar-unverified-provenance.png` 复制自本地 `resource/knightavatars/edelweiss.png`。来源未追溯，仅用于补充观察，不作为官方设定证据。此次检查的动画官网人物页不包含爱德怀斯人设，未获得可追溯动画官方爱德怀斯配色图。

第七卷彩页的青蓝眼爱德怀斯为莎拉〈幻想戯画〉的复制体与战斗光效场景，不作为真人日常配色的优先来源。

## 本次上色建议

以下 HEX 是为了在黑白原稿上实现已核验颜色的工作建议，并不是官方提供的固定色号。

| 分区 | 建议色 | 依据级别 |
| --- | --- | --- |
| 白发明部 | `#F2F4EF` | 白发为原著明确；此色号为配色建议 |
| 白发一般阴影 | `#C9D0CC` | 官方彩图银灰/微绿灰阴影；此色号为配色建议 |
| 白发深阴影 | `#8C9898` | 官方彩图冷中性深阴影；此色号为配色建议 |
| 银灰虹膜主体 | `#A7A2AD` | 原著明确银灰；少量灰紫来自 Won 彩图反光 |
| 虹膜亮部 | `#DEDCE4` | 低饱和银灰亮部，保留原稿高光 |
| 虹膜深部 | `#68626C` | 低饱和深灰紫，保留原稿暗线 |
| 白皙肤色 | `#FFF1DF` | 原著白皙与 Won 暖肤色；避免照搬封面强黄光 |
| 肤色阴影 | `#E5C2B4` | 调色建议，控制暖粉灰 |
| 针织上衣 | 暖象牙白 `#F2EADD`，阴影 `#C4BAB1` | 当前尚未核验此套私服官方彩色版本；设计适配 |
| 牛仔裤 | 中性低饱和靛蓝 `#647B98`，暗部 `#35485F`，亮部 `#94A7BB` | 用户明确要牛仔裤插图；蓝色强度为设计适配，非官方确认 |

分区注意：白发用略冷的银灰，上衣用暖象牙白，脖子用淡暖肤色，边界保持原线稿，可避免三个浅色区域融成一片。原稿黑线、阴影、针织与牛仔纹理须保留。
