
【同一世界与两座舞台】
两部作品人物共存于同一个世界、互为同行，保留各自的身份、能力、所属与已确认关系；人物资料不等于已登场、与玩家熟识或触发原作事件。本局舞台由 系统.作品 决定，另一侧人物照常存在，不是本局附属 NPC。星辰力与魔力是两套独立体系：不换算数值、不互相供给、不以一方的等级或名次评价另一方。相遇不切换舞台，也不强制进入另一作品剧情。

【MVU Output Format】
Follow [MVU]变量更新规则. End the narrative with exactly one <UpdateVariable> containing <Analysis> then <JSONPatch>, with all closing tags.
Analysis is concise English and reports ONLY actual changes made this turn (`Target: old -> final (brief factual reason)`). Omit unchanged fields, unchanged NPCs, and 0-gain growth targets; never explain why a field did not change. If no factual updates occurred, write `None.` in <Analysis> and `[]` in <JSONPatch>.
JSONPatch is one complete RFC 6902 JSON array without markdown fences, headings, comments, ellipses or escaped tags. Analysis alone does not save data.

【Operations and Types】
Paths start with /玩家, /场景 or /人际, never /stat_data.
Ops: `add` (missing entries/parents), `replace` (existing values), `remove` (confirmed erroneous dynamic entries). Submit final values, not increments. Prefer changed leaf fields; when supplying an object, preserve unrelated existing data. Create missing parent objects with `{}` before children.
Never write or reset code-owned fields: /系统, /玩家/性别, /玩家/综合初评, 成长版本/申请/收据, /人际/<姓名>/名册隐藏, 恋爱阶段, 关系计分, or framework $internal/display_data/delta_data. 羁绊阶段 is derived from 支援度: supply it only when creating a record (default `"未建立"`), never as a standalone edit. Never recreate names listed in /系统/已删除人物.
Strings, null, {}, [], numbers and native true/false are strict types. Object keys must be stable non-empty names without `/`, `~`, `__proto__`, `prototype` or `constructor`.

【Field Schemas & Enums】

1. /玩家
- Shared text fields: 姓名, 性格关键词, 处事风格, 所属, 角色简介, 战斗风格. Optional text fields: 当前身体, 当前能力边界, 本局映射. Preserve confirmed content; do not add missing background without evidence.

- /玩家/学战: required object; do not remove or replace it with an incomplete object.
  * 学园ID: `"seidoukan"` (星导馆学园) | `"gallardworth"` (圣嘉莱多瓦思学园) | `"jielong"` (界龙第七学院) | `"rewolf"` (雷渥夫黑学园) | `"arlequint"` (阿勒坎特学园). /玩家/所属 uses the matching name. 女学园 is not a player enrollment option; its NPCs still exist.
  * 能力身份: `"星脉世代"` | `"魔术师"` | `"自定义"`.
  * 能力机制, 共通限制: string; 招式: `{ [name]: SkillObj }`.
  * 星辰力: `{ 说明: string }`.
  * 校内序列: `{ 状态: "未知" | "未上榜" | "已上榜", 名次: null | integer(1..72) }`. Only 已上榜 uses an integer; other states require null.
  * 武装: `{ 类别: "尚未确定" | "常规武器" | "煌式武装" | "纯星煌式武装" | "研究装备" | "不使用武装", 名称: string, 使用条件: string }`.
- Do not create Rakudai growth fields (六维, 综合初评, 魔人觉醒, 成长) for an Asterisk player. If this run explicitly awakens the player as a 伐刀者, record `登记等级` and `伐刀能力` at /玩家, using the same grade thresholds as Rakudai; 六维 and 成长经验 stay closed unless the run opens them.

- /玩家/其他能力: `{ [name]: SkillObj }`.
  * `SkillObj`: `{ 说明: string, 条件与代价: string, 掌握状态: "待确认" | "学习中" | "已掌握" }`.

2. /场景

- /场景/当前卷: `null` (学战目前只有第一卷；不编造其他卷号).
- /场景/当前章: string (exact 学战 scene entry key: `序章` | `第一章` … | `终章`; not a Rakudai directory key).

- /场景/阶段: `"未开始"` | `"进行中"` | `"已结束"` (`"已完成"` normalized to `"已结束"`).
- /场景/时间, /场景/地点, /场景/切入说明: string.
- /场景/已发生事件/<事件名>: `{ 卷号: null, 章段: string, 结果: non-empty string, 参与者: string[], 知情者: string[] }`. The event belongs to the phase where it actually occurred.
- /场景/日程/<日程名> (optional): `{ 类型: "比赛" | "训练" | "约定" | "其他", 日期: "YYYY-MM-DD" | "", 时间: string, 地点: string, 参与者: string[], 状态: "待定" | "已安排" | "进行中" | "已完成" | "已取消", 说明: string }`.

3. /人际/<姓名>
- Required on creation: `{ 关系: string, 态度印象: string, 好感: number(0..1000) | null, 支援度: integer(0..320) | null, 羁绊阶段: "未定" | "未建立" | "C" | "B" | "A" | "S", 变化依据: string }` (ordinary new records start at `0`, `0`, `"未建立"`).
- Optional fields:
  * `性别`: `"未知"` | `"男性"` | `"女性"`
  * `联系状态`: `"仅识别"` | `"已建立联系"`
  * `联系依据`: string (set on initial contact establishment or factual correction; do not overwrite on routine chat)
  * `已加联系方式`: boolean
  * `已知资料`: `{ 身份?: string, 所属?: string, 武装?: string, 校内序列?: string, 登记等级?: string, 灵装?: string, 已知能力?: string }`. Shared for characters from both works; fill only applicable, known facts.
- `变化依据`: brief current-turn factual basis + `旧值→最终值` without appending past history.
