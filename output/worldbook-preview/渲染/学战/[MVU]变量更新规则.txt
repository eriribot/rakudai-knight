
【同一世界与两座舞台】
两部作品人物共存于同一个世界、互为同行，保留各自的身份、能力、所属与已确认关系；人物资料不等于已登场、与玩家熟识或触发原作事件。本局舞台由 系统.作品 决定，另一侧人物照常存在，不是本局附属 NPC。星辰力与魔力是两套独立体系：不换算数值、不互相供给、不以一方的等级或名次评价另一方。相遇不切换舞台，也不强制进入另一作品剧情。

【变量更新规则】

本局舞台为 学战都市（六花）。两部作品人物共存于同一个世界、互为同行，各自保留身份、能力与所属机构，不是对方的附属 NPC；按本局地点和已知关系自然互动，人物资料可参考但不等于已登场、与玩家熟识或触发原作事件，未知秘密不写入玩家已知资料。
星辰力与魔力是两套独立体系：不换算数值、不互相供给、不以一方的等级或名次评价另一方；跨体系交手只描述可见结果，不写成能量转换。相遇不切换舞台，不强制触发另一方作品的主线事件。
先读本分支旧值，再核对本轮事实，提交最终值。本局剧情、玩家设定与已保存变量优先于原著默认走向和模型记忆；不强制还原胜负、关系、死亡、觉醒时间或能力。不代玩家决定行动、内心、台词；计划和预告不记成已完成。
主副 API 共用业务字段权限。主回复每轮自行检查场景、成长、遇见或互动人物的好感与支援、联系资料及赛事事实；实际变化当轮提交，不等副 API 或玩家提醒。不因没有重大事件、没有自身成长而略过日常人际变化。补漏与重试均使用当前聊天、楼层和回复页，只补漏或纠错，同一成果、重试和副校正不再次相加。

【保存与字段】
已建档不重建；待建档补丁为 []，由开局页完成建档。v2/v3 先经终端迁移；一辉模式不另建同名 NPC。固定字段及数据类型见输出格式。
字段所有权以输出格式为准：代码维护 /系统、性别、综合初评、成长版本与收据、名册隐藏、恋爱阶段及框架元数据。旧成长申请与收据只读留档；模型更新业务事实，不覆盖父对象重置它们。/系统/已删除人物 随分支保存，不从旧正文重建其中人物。
玩家资料、能力、六维、正式登记等级、成长经验最终值、人际资料及分数均可按已确认事实修正；不另需终端审批。通常写具体叶字段；合并已有对象时保留未提到的资料。能力、事件、人际中的错误条目可以删除，离场或暂时失效不等于删除。


【学战能力、武装与序列】
使用 /玩家/学战，保留 /玩家/所属 为所属学园名称，学园ID使用固定代码；只有实际转学或已确认纠错才一起更新。不因遇见其他学园人物就转学。
能力身份、能力机制、共通限制、招式分别保存；武术、分析、生活技术归 /玩家/其他能力。技能沿用说明、条件与代价、掌握状态，不把原作未来招式或仅提出的建议记成已掌握。星辰力以 /玩家/学战/星辰力/说明 记录实际控制、运用与负担，不编造统一数值、HP/MP或经验等级。
武装保存类别、名称、使用条件；自身异能与武装功能分别描述。纯星煌式武装的资格、适合情况和代价以已确认事实为准，未知不补造百分比。获得、失去、改造或条件变化才改武装；没有武装不能凭空授予。
校内序列只表示所属学园排名：已上榜填1至72整数，未知或未上榜的名次为null。前12名属于始页十二人。只按已发生的正式结果或确认纠错改排名，不按战力猜名次、不为设定的名次倒补战绩。
成长按实际学习、练习、改良或突破更新文字与技能掌握状态。/玩家 默认不建伐刀能力、固有灵装、六维、登记等级、综合初评、魔人觉醒或落第成长经验；本局明确觉醒为伐刀者时，按输出格式补 /玩家/登记等级 与 /玩家/伐刀能力，六维与成长经验仍不开。跨体系能力只有玩家明确确认才记在能力机制、本局映射或其他能力中，不自动获得。


【剧情、事件与日程】

学战按注入的学战场景条目推进：/场景/当前章 用条目键（序章、第一章…终章），/场景/当前卷 与已发生事件卷号保持 null——学战目前只有第一卷，不编造其他卷号。完成标识、相邻节点、每轮节奏与交接方式沿用上面同一套规则；目录没有下一个条目时保持当前章并停下，不改用落第卷章目录，也不擅自进入选拔赛、七星剑斗祭或 A/B 路线。
六花岛闭关是既有设定：岛内人物知道外界之事但不离岛活动；玩家行动不得解除封岛、改动岛屿归属或改动大教授的物资与返乡名额制度。原著主线照常发生，玩家可介入并改变本局结果，但不另造一条脱离学园决斗的新主线。

完成事件归推进前章节；提示里可见的最近事件沿用原键补全，更早的事件只新增键名、不改写旧条目。只保存已发生结果，不写未来章节，不把不知情者列入。场景时间、地点、切入说明按实际情况更新，未知不编具体日期。日程只记本局已知安排，未知日期留空；实际开始/完成再改状态，完成另记事件。过期、缺席、未来原著安排不自动视为发生。取消或改期保留原条目和依据。

【人际与分数】
本局实际识别或明确认识的人物可建档；名单和传闻不等于见过。保留亲属、师生等背景关系，不因低分当陌生人。联系状态记录仅识别/已建立联系，首次双向言语或行动即建立联系；联系依据简记建立联系时的双方行动，后续日常互动不覆盖已有联系依据。已加联系方式独立，只在渠道成立时为 true，不以面对面交流代替。
按事实补性别、身份、所属、武装、校内序列、登记等级、灵装、已知能力；仅填写适用且已知的资料，不把学战序列换算成落第等级，不填世界书秘密或未来资料。两作品人物都可能觉醒为伐刀者：学战出身的魔女、魔术师与其他星脉世代可按本局事实补 登记等级、灵装与已知能力，等级用同一门槛和实际表现评定，不因出身拒绝；落第人物同样可在 已知资料 记星辰力相关资料。觉醒只改变其能否使用该体系的能力，不把两种能量合成一种，也不迁移对方的等级或名次。普通新人物好感/支援从0计，已确认背景可按实际深度直接核定。旧数字续算，不归零套初见奖励；未知/旧null保留待核定，可在事实明确时修正。
好感表现对玩家态度变化，支援表现落实的支持、协作和信任，二者独立。正常友善回应可有普通好感+2—10；新生轻微好感、认可或防备缓和可参考中度+11—20；重大关系改变可参考重度+21—40。负向变化按实际影响核定，支援日常协作可参考+1—5、克服阻碍+6—10、重大协作+10—15。这些为叙事尺度参考，不是硬上限或审批分类。
有对应回应就及时改分，不能只改态度印象；仍羞恼、没有恋爱、没有重大事件不等于无好感。只有玩家单方示好不强加对方好感；闲聊或许诺不自动增加协作支援。变化依据用一句简短事实记本轮变化与旧值→最终值，不追加历史旧依据，不要求独立突破依据、固定关键词或换措辞。一次回复给每人每项一个合并终值；后续可纠错终值，不能将重放补丁作为新奖励。
羁绊由支援派生（0—79未建立、80—159 C、160—239 B、240—319 A、320 S）。恋爱阶段只对已确认女性且好感有效者派生（0—199路人、200—499在意、500—799暧昧、800—999交往、1000生死相随）。阶段是表现参考，不倒补未发生告白、婚约或亲密经历，不授予觉醒。
