# 放课后的约定 · OC 对战演示

独立目录中的第一人称卡牌对练 Demo。玩家是可命名的自定义主角；中央只有迎面的史黛菈，玩家状态与手牌放在画面下方。绫辻绚濑是可展开查看、每场支援一次的「真命天女」羁绊卡。

## 启动

在仓库根目录执行：

```powershell
node ocgame/serve.cjs
```

打开 <http://127.0.0.1:4178/>。服务只监听本机。端口可以用 `OCGAME_PORT` 修改。无需安装前端依赖。

## 已实现

- 自定义姓名、长剑／太刀／细剑；设置保存在本浏览器。切换主角会开始新对练。
- 12 张牌、6 种牌型；每回合 3 行动、抽 5 张，弃牌堆用尽后重新洗入。
- 史黛菈按「斩击 14 → 架势 14 护盾 → 烈焰斩 23」循环，意图提前显示。
- 普通斩击、穿透、护盾、蓄力、抽牌、胜败结算、再次对练。
- 绚濑「并肩」：回复最多 12 生命，获得 8 护盾，不消耗行动，每场一次。
- 史黛菈正面待机／挥砍两姿势，35 ms 起手、65 ms 突进残影、85 ms 斩击、90 ms 归位。动作只平移整个人物，不单独缩放头部。
- 命中斩光、冲击圈、火花、伤害数字、镜头震动；重开会中断旧回合和效果。
- 桌面与手机布局、可横向滑动的手机手牌、键盘操作、减少动态效果偏好。

`1–5` 出牌，空格结束回合，`Esc` 关闭窗口。手机可以左右滑动手牌。卡面点开后能查看完整插画与支援效果。

这版使用独立的演示数值，不读写 MVU，也不包含一辉、一刀修罗或一刀罗刹的解锁。原 `cardgame` 未由本次实现修改。

## 验证

```powershell
node --test ocgame/engine.test.mjs
```

逻辑验证覆盖护盾结算、行动点限制、支援次数、武器差异、蓄力与穿透、牌数守恒与回收、三种武器可胜出、失败与重开。

浏览器脚本及截图在 `output/playwright/ocgame/`。验收记录见 `docs/verification.md`。没有连接 SillyTavern 或验证 MVU 宿主接入。
