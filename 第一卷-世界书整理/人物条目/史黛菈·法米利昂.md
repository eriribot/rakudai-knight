# 史黛菈·法米利昂（Stella Vermillion）

- **人物 ID**：`char-stella-vermillion`

- **别名/触发词**：史黛菈、Stella Vermillion、红莲皇女、妃龙罪剑、妃龙吐息、燃天焚地龙王炎
- **首次出场**：第一卷序章
- **系列关键出场**：
  - 第一卷：破军学园开学入学、405 室换衣误会与开学决斗；败于开挂般的一刀修罗后成为同室室友；购物中心恐袭中主动立于前线抗敌救援平民；选拔战面对全场偏见当众拔剑怒斥为所爱之人声援；
  - 第三卷：奥多摩集训中展现扎实的野炊烹饪技能与食量相当于常人四倍的肉食系大胃王反差；
  - 第四至五卷：重力地狱特训，体能与剑速脱胎换骨；
  - 第八至九卷：准决赛领悟概念干涉〈自知巨龙〉正面撕裂王马天灾风暴；决赛施展数百米光剑展开顶峰世纪死斗；
  - 第十三卷：法米利昂保卫战打破常人枷锁，正式觉醒为《魔人（Desperado）》，化身真龙守护祖国。
