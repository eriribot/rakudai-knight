# 管茂信

- **人物 ID**：`char-shigenobu-kan`
- **显示名**：管茂信
- **别名/触发词**：管茂信、管、白雷刃、三年级 C 级骑士
- **首次出场**：`MAT-001#L5,602-L5,608`
- **出现章节**：`CH-04`
- **类别**：选拔战对手／高年级学生骑士

## 身份与第一卷定位

管茂信是破军学园三年级 C 级骑士，曾在与贪狼学园的交流赛中取胜，被认为拥有丰富实战经验。他在七星剑武祭出赛权选拔战首日与珠雫交手。

## 能力与战斗

- 固有灵装：双剑型态，带有雷电效果。
- 使用雷属性攻击 `白雷刃`，试图利用“雷克制水”的常识压制珠雫。
- 珠雫用高精度水流和近似绝缘的超纯水抵消其优势，最终获胜。

来源：`MAT-001#L5,598-L5,618`、`MAT-001#L5,630-L5,678`

## 卷末状态

在选拔战首日失去战斗能力，败给珠雫；第一卷没有继续交代其之后的比赛。

## 世界书摘要

管茂信是破军学园三年级 C 级骑士，使用双剑型雷属性固有灵装和“白雷刃”。他在选拔战首日试图用雷克制水，却被珠雫以高魔力控制制造的超纯水防御化解并击败。不要把他的属性优势写成必胜规则。

## 禁止误写

- 管茂信是选拔战正式选手，不是解放军成员。
- “雷克制水”是他采用的战术判断，不是无法被能力控制破解的世界绝对法则。
