## 学战范围

开放星导馆、圣嘉莱多瓦思、界龙第七、雷渥夫黑、阿勒坎特五所学园，卡片与详情使用真实彩色校徽。女学园入口已移除，本版本只支持男性玩家；女校或非法学园档案会被拒绝导入，世界背景仍可包含女校。

每所学园各有 72 个在名序列名额：第 1–12 名在名单第一页，称为“始页十二人”；第 13–72 名同样在榜，未上榜为独立状态。该规则来自第一卷第一章“华焰魔女”，详见[原文核验](E:/web/落第/第一卷-世界书整理/开局网页正则替换/rank-source-verification.md)。序列是校内排名，不是跨学园通用战力等级；界面、复制文案与两类 AI 提示词均使用此规则。

学战使用独立草稿，不套用落第 A–F 评定。确认只生成可复制开局草稿，不向落第 MVU 提交学战人物或场景。存档使用独立浏览器键，兼容旧落第档案。学战封面收录第 1–13、15–17 卷，第 14 卷素材缺失；8 张彩插用于漂浮展示与原有插画册。

## OP 与切换

两世界共用原落第页面的用户剪辑 OP。首次进入和独立“重播 OP”按 OP → 标题页 → 小说首页进入。顶部作品 Logo 直接切换页面、主题与草稿，不重播 OP。BGM 原先播放则续播目标世界音轨，原先暂停则保持暂停；换学园不重载音轨。

只有文件预览，或 `localhost` / `127.0.0.1` 且路径包含 `/开局网页正则替换/` 的入口，优先播放根目录 `op.mp4` 的原样副本；本地失败仅回退原 OP URL 一次。外部托管与本机酒馆入口直接使用原 OP URL。`preview=1` 不跳过初次 OP，仅调试参数 `skipIntro=1` 跳过。

视频节点就绪后立即尝试有声自动播放；环境阻止有声时自动静音播放，显示不阻塞画面的“开启声音”按钮，点击后从当前位置开启声音。OP 期间 BGM 暂停。
