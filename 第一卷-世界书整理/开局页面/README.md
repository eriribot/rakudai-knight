## 历史原型说明（以下内容对应 2026-09-02 版本）

这是《落第骑士英雄谭》第一卷的独立开局页面原型，当前定位为 **prototype/source**，不是可直接导入的 SillyTavern 角色卡、独立世界书或发布包。

## 当前文件

- `index.html`：纯 HTML/CSS/JS 页面，使用 `lk-opening-*` 命名空间；内置 SVG 雷达图、档案切换、六轴明细、草稿表单、只读预览、本机保存与复制降级。
- `profiles.json`：第一卷档案数据源。包含黑铁一辉、史黛菈·法米利昂、黑铁珠雫三个 `canon` 档案，以及一个 `custom` 模板。
- `data-contract.md`：字段、状态所有权、事实边界与未来 ST 接入契约。

## 资料边界

页面使用第一卷作者源 `MAT-001`，而不是输入卡《大凉龙虎传》的武侠事实。三名角色的六轴资料页均为第一卷原文直接给出：

| 档案 | 六轴来源 |
|---|---|
| 黑铁一辉 | `MAT-001#L3,522-L3,544` |
| 史黛菈·法米利昂 | `MAT-001#L5,569-L5,591` |
| 黑铁珠雫 | `MAT-001#L7,546-L7,568` |

六轴固定为：攻击力、防御力、魔力量、魔力控制、体能、运气。伐刀者等级单独显示，不是第七轴。A–F 只被等距换算为 SVG 的视觉半径，页面明确提示这不是等差实值，也不等同于实战强弱。

一辉的 F 级不能被解释为不会战斗；珠雫的“障波水莲/障破水莲”保留为第一卷字形变体；未有六轴资料的角色不通过称号、战斗胜负或外部资料反推数值。恋人状态、“无冕剑王”、桐原败北等后段状态没有写入基础开局档案。

## 状态所有权

- **作者源档案**：`profiles.json` 与第一卷 Markdown；页面只读取。
- **draft state**：表单输入与自定义雷达值；只在页面内编辑，可通过版本化 key `luodi-knight-opening-draft-v1` 保存到本机浏览器。
- **UI state**：当前预设、展开/焦点、提示状态；不持久化为游戏变量。
- **derived view**：雷达图、六轴明细和预览文本；由当前档案/草稿派生。
- **提交状态**：本轮没有自动发送，也没有“已入局”假状态。复制按钮只复制文本；复制失败时选中预览区，用户仍可手动复制。

## 从输入卡借鉴但未迁移

保留的是“预设 → 表单 → 预览 → 草稿保存/复制”的交互骨架和命名空间化适配思路。没有迁移输入卡的 481 条大凉世界书、CR/境界/骰子规则、MVU/EJS/Tavern Helper、23 条正则、大块 HTML 正则替换、远程加载器、状态栏或自动发送路径。

## 运行

直接用浏览器打开 `index.html` 即可预览。由于页面读取同目录的 `profiles.json`，某些浏览器的 `file://` 安全策略可能阻止 `fetch`；此时页面会安全退回空白自定义档案。使用本地静态服务器预览时应仅提供此目录，不上传第一卷原文或其他私有材料。

## 后续接入 gate

若要接入 SillyTavern，必须另行确定目标版本、实际挂载层、`first_mes`/原生 opening 与 Regex 方案、是否启用 MVU/Tavern Helper、初始化写入者和正常发送 API。之后再把本原型交给 `sillytavern-card-pipeline` 与 `sillytavern-runtime-debug` 做导入、消息创建、重载/切聊天、移动端和真实关键词/生命周期验收。离线预览不等于运行时通过。
