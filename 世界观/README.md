## 二、 格式规范与架构标准

每个世界观 Markdown 文件均严格按照三段式工程学规范编写：
1. **一、 设定全景与联网检索考证 (Setting & Background Dossier)**：包含日文原名对照、组织法理溯源、战术技艺拆解与隐藏世界线深度考究。
2. **二、 原著小说核心原文实录 (Original Novel Canonical Excerpts)**：原汁原味摘录对应卷次章节的核心大段原文，包含剧情转折、战术交锋与社会思想交锋的原文铁证。
3. **三、 世界书 / TRPG 跑团联动机制与判定规约 (Worldbook & Mechanics Specification)**：规范了精准触发词、环境加护标签、伤害检定 DC、豁免惩罚与 AI 叙事一致性守则。
