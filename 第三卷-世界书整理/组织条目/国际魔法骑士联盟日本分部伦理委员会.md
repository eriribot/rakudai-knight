# 国际魔法骑士联盟日本分部伦理委员会

- **组织 ID**：`org-ethics-committee-japan`
- **显示名**：国际魔法骑士联盟日本分部伦理委员会
- **别名/触发词**：伦理委员会、联盟伦理委员会、骑士伦理委员会、特别调查委员会
- **隶属关系**：国际魔法骑士联盟（Rebellion）日本分部直属监察机构
- **最高掌权者**：黑铁严（日本分部长统管）
- **现任执行官/委员长**：赤座守（黑铁分家当家）
- **核心职能与权力机制**：
  1. **骑士资质审查与司法调查权**：负责对涉嫌违反《魔法骑士法》、违背骑士伦理或扰乱公共秩序的伐刀者与学生骑士展开强制调查；
  2. **除名申请权**：经调查判定不适任者，可直接向联盟总部提出取消伐刀者资格及“骑士除名处分”；
  3. **地下特别拘留所**：设有脱离学园自治体系与常规司法的独立地底审讯收容设施；在第三卷中，赤座守滥用职权在此动用 24 小时强光直射、强制剥夺睡眠数天、连续罚站、断水绝食以及战后禁用的“宪兵自白剂”对黑铁一辉进行非人道刑讯逼供，企图迫使其签署自愿弃权书；
  4. **政治工具属性**：表面为维持骑士道德之纪律监察机关，实为黑铁宗家（黑铁严）与保守派高层用以打压异端、排除 F 级劣等生逆袭、维护阶级秩序的行政打手。
- **第三卷最终下场**：
  随着黑铁一辉在第 20 战中于全国电视直播前一刀斩断雷切登顶，赤座守在通道行凶未遂被史黛菈揍飞重伤，伦理委员会构陷学生的阴谋彻底大白于天下，其政治信誉全面崩溃。
