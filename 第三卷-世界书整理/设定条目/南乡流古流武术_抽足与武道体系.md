# 设定条目：南乡流古传武术

流派名：南乡流古传武术（南乡寅次郎传授之武道体术与剑技）

- **流派起源**：由二战传奇魔法骑士、日本初代国家代表队领袖、中国顶尖“斗神杯”联赛中唯一夺冠的日本人、享有〈斗神〉与二战〈无缺〉之名的古流武道大宗师**南乡寅次郎**创立并传授的古流武道/体术绝学（`MAT-003#L899-909`、`MAT-004#L4753`）。该武术体系不依赖任何大范围元素轰炸与破坏魔法，以极其精密的古流呼吸法、潜入对手潜意识的步法、回旋化解万钧冲击的极致柔化防御，以及十步之内将敌人意识一刀两断的音速拔刀术著称。

- **代表传承人物**：
  1. **〈斗神〉南乡寅次郎**：流派开创者与大宗师，高龄九十余岁的日本现役最年长魔法骑士，名副其实的“活传说”。二战期间经历场场恶战的南方作战，唯有他毫发无伤存活到最后一刻，赢得〈无缺〉美名（`MAT-014#L847`）；
  2. **〈夜叉姬〉西京宁音**：南乡嫡传门徒，深得南乡传授的〈抽足〉与〈剑之舞〉真传，将之与自身日本舞踏直觉及重力魔法相融，升华出防御绝技〈夜叉神乐〉（`MAT-003#L847`、`MAT-014#L1539`）；
  3. **〈雷切〉东堂刀华**：南乡在初中合宿时相中的秘传弟子，继承了南乡亲自传授的超音速拔刀居合术，结合自身雷电魔法开创出名震关东的必杀技〈雷切〉（`MAT-003#L915`、`MAT-003#L2224`）；
  4. **浅木椛**：武曲学园三年级生、去年七星剑武祭季军（全国第三名），称号〈鬼火〉。脸颊贴着OK绷的俏皮短发少女，与诸星雄大、城之崎白夜并称武曲三巨头，同为南乡寅次郎传授步法的门生，精通流派步法〈抽足〉（`MAT-007#L203`、`MAT-009#L832`）；
  5. **黑铁一辉**：虽非门下，但在第三卷凭借自身武道眼界一眼看穿〈抽足〉的心理潜意识构造并成功复现（`MAT-003#L875-885`）；第七卷开创性地将原本对单人使用的〈抽足〉与普通步法交替使用，成功错乱数百具死灵军队的步枪集火瞄准（`MAT-007#L4803-4807`）；第十八卷亦以此步法滑入死角隐形。

- **流派精髓·“潜入潜意识之隙，化一切冲击于回旋”**：
  南乡传授的武道完全建立在人类心理知觉与精纯体术之上：在步法上，通过呼吸法卡入对手大脑对不必要情报的过滤缝隙，达成“明明看得见却无法察觉”的潜行；在防御上，身躯如舞蹈般顺势回旋，将敌方刀剑拳脚的所有冲击力全部归于虚无；在拔刀出招上，构建步入即斩的“死地”，出鞘瞬间超越音速一刀两断。

- **步之极·〈抽足（抜き足）〉**：
  结合古老武术的呼吸法与步法所产生出来的体术技巧（`MAT-003#L843`）。
  其原理在于：小心翼翼地进行源自禅修经行的**“半步呼吸”**（以一呼一吸迈半步的方式推进，`MAT-003#L887`），并且轻移身躯，从清醒意识的隙缝中悄悄滑进潜意识，开启对手的“意识之锁”。
  人类大脑为了防止处理眼耳接收的一切情报导致过载，本能地会将低优先级情报塞入“清醒意识中的潜意识”，通过放弃辨识来减轻负荷。施展者通过此步法将自身存在滑进对方潜意识，对手大脑与双眼虽然确实捕捉到了其身影，意识却将其归类为“不必要的情报”而无法辨识。直到生死受威胁的前一刻，对手才会勉强反应过来（`MAT-003#L877`）。
  - **破解法**：受术者必须主动正视“觉醒意识中的潜意识”。如同眼前有人持枪指着自己时，必须强迫自己违背自保本能移开死盯枪口的视线，转而去注意对方耳环品牌一样无关紧要的背景（`MAT-003#L941-961`）。
  - **战场大军演进**：第七卷一辉对阵平贺玲泉的突击步枪死灵军队时，频繁交替使用〈抽足〉与普通步法，分散受击标的，导致死灵军队的步枪集火瞄准全面错乱脱靶（`MAT-007#L4803`）。

- **御之极·〈剑曲·剑之舞（剣曲·剣の舞）〉**：
  南乡寅次郎在二战南方作战毫发无伤存活、名震战场的绝对防御绝技（`MAT-014#L847`）。
  以极为柔软的防御接下敌人的刀剑，身体如舞蹈般回旋，将所有冲击力归于虚无（`MAT-014#L847`）。该剑招与黑铁龙马攻防一体的〈天衣无缝〉截然不同，它完全排除反击的机会，剑招本身全力维持守势，以待威胁度过（`MAT-014#L873`）。面对世界级拳士纳西姆的狂暴重拳，该剑舞能彻底消除拳脚力道，毫发无伤。

- **拔之极·〈音速拔刀术〉**：
  南乡寅次郎享誉世界的立足根基，现代超音速居合术鼻祖。
  像南乡这种等级的剑士，其攻击范围几乎等同于对手的“死地”，只要轻易踏入一步，其拔刀就能瞬间将敌人的意识一刀两断（`MAT-004#L4745-4747`）。以迅雷不及掩耳之速拔刀，又以相同速度收刀，声未落而刃已斩（`MAT-018#L2269`）。

- **派生奥义·〈雷切〉**：
  东堂刀华将南乡传授的超音速拔刀术，结合自身雷电魔法升华而成的独门必杀（`MAT-003#L909-915`）。在音速居合出刀轨迹中注入电磁力加速，十步之内超音速斩杀，出刀伴随雷鸣电闪与强烈激波。

- **派生奥义·〈夜叉神乐〉**：
  西京宁音将南乡亲传绝技〈剑之舞〉，以自身日本舞踏美感与重力魔法升华至更高境界的绝技（`MAT-014#L1539`）。身段柔软优美，轻盈舞动身躯，在有效攻击距离内封杀世界级强者的狂暴拳脚攻势，让敌人毫无可乘之机。
