# 平贺玲泉（Reisen Hiraga）

- **人物 ID**：`char-reisen-hiraga`

- **别名/触发词**：平贺玲泉、玲泉、小丑、Pierrot、傀儡师、人偶师、军队刺客

- **系列关键出场**：
  - 第三卷第二章暗线：身处于东京某处阴暗密室内，使用中继人偶与百公里丝线操纵奥多摩山中的大批岩石巨人傀儡袭击巡逻木屋，进行测试。左手因刀华雷电顺线电焦炭化，谈笑间轻动右手令焦黑左臂完整脱落，与黑铁王马（高大黑影）对话，谈及测试与晓学园的莎拉（“用胶水黏翅膀的猫/史芬克斯”），在王马离开后叹息其应多学学“单纯的弟弟（一辉）”；
  - 第四至十卷：作为反体制势力“晓学园”的核心骨干与傀儡操纵者，在七星剑武祭掀起暗黑风暴。
