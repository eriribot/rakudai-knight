# 黑铁王马（Ouma Kurogane）

- **人物 ID**：`char-ouma-kurogane`
- **显示名**：黑铁王马
- **日文原名**：黒鉄 王馬（くろがね おうま，Kurogane Ouma）
- **别名/触发词**：黑铁王马、王马、烈风剑帝、黑影男子、断空、断空黑铁、晓学园客座、武曲学园
- **声优（CV）**：【动画第一季未直接登场 / 暗线仅为黑影】
- **首次出场**：第三卷第二章（奥多摩暗线，以伫立在平贺玲泉身后的高大黑影现身）
- **系列关键出场**：
  - **第三卷第二章暗线**：伫立在平贺玲泉身后阴影中，神色轻蔑注视其电焦炭化的左臂；冷酷拒绝平贺奉上的焦黑断手，直言丢给“猫（莎拉·布拉德莉/史芬克斯）”当饲料；坦承自己为了与红莲皇女（史黛菈）一战才陪晓学园耍猴戏，丢下一句“想说废话就去跟镜子说，小丑”后冷酷离去；平贺在其离去后感叹其应多学学“单纯的弟弟（一辉）”；
  - **第四至九卷（七星剑武祭篇）**：正式以晓学园客座身份登场（原为关西名门武曲学园三年级，日本学生中唯一的 A 级骑士），展现所向披靡的〈烈风剑帝〉绝对统治力。在半决赛（第二准决赛）中与法米利昂皇国的〈红莲皇女〉史黛菈展开倾尽全力的超人死斗，最终惜败于史黛菈；随后在看台见证弟弟黑铁一辉在决赛战胜史黛菈登顶全国七星剑王；
  - **第十六至十九卷（世界大战篇）**：作为日本顶尖战略级战力迎战境外魔人联盟入侵，展现独行修罗的极道剑刃。
- **类别**：晓学园客座选手（Guest，学籍原属武曲学园三年级） / 原黑铁家长男（中学时已离家出走流浪、与黑铁家及父母断绝一切血脉羁绊） / 一辉与珠雫的血脉兄长 / 日本学生唯一的 A 级骑士 /〈烈风剑帝〉
