# 黑铁严（Itsuki Kurogane）

- **人物 ID**：`char-itsuki-kurogane`
- **显示名**：黑铁严
- **别名/触发词**：黑铁严、严、当家大人、日本分部长、联盟分部长、黑铁家当主、黑铁委员长、铁面政客、冷血父亲
- **首次出场**：第三卷第二章（联盟分部长室电话）／第三卷第三章（地底囚室与一辉正面对峙）
- **系列关键出场**：
  - 第三卷第二章：在骑士联盟日本分部高层统揽全局，听取珠雫败北战报，默许赤座守动用媒体与行政审查打压一辉；
  - 第三卷第三章：亲临不见天日的地底收容所牢房，隔着审讯桌与绝食虚弱的一辉展开父子一对一对峙；以现代魔法骑士制度的秩序卫道士身份，冷酷勒令一辉主动退学以换取一生衣食无忧，被一辉坚决回绝；
  - 第八至九卷：在七星剑武祭全国大赛高层视察，目睹长子黑铁王马与次子黑铁一辉的巅峰对决；
  - 第十七至十八卷：面对境外魔人联合侵略东京本土，以最高分部长之姿坚守国家指挥中枢。
- **类别**：国际魔法骑士联盟日本分部部长 / 黑铁宗家现任家主 / A 级骑士 / 一辉·王马·珠雫之父
