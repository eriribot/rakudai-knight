# 黑铁严（Itsuki Kurogane）

- **人物 ID**：`char-itsuki-kurogane`
- **显示名**：黑铁严
- **日文原名**：黒鉄 厳（くろがね いつき，Kurogane Itsuki）
- **别名/触发词**：黑铁严、严、当家大人、日本分部长、联盟分部长、黑铁家当主、黑铁长官、铁血
- **声优（CV）**：速水奨（TV动画版）
- **首次出场**：第三卷第二章（联盟分部长室）／第三卷第三章（地下特别拘留所牢房探视）
- **系列关键出场**：
  - **第三卷（破军篇）**：在联盟分部统揽全局；深夜亲临地下特别拘留所，向一辉道出冷酷的“阶级齿轮论”，要求其退出骑士界，其视若路石的绝对冷漠彻底摧毁了一辉的精神支柱；
  - **第七至九卷（七星剑武祭篇）**：以联盟最高监察身份坐镇高层贵宾席，目睹早已彻底脱离黑铁家断绝关系的长子黑铁王马（自立修罗作为晓学园客座出战）在半决赛败于史黛菈，而曾被自己视作无才能并下令退学的次子黑铁一辉一路击败诸星雄大等顶尖豪强、并在最终决赛巅峰战正面战胜史黛菈登顶七星剑王；
  - **第十六至十九卷（大战与世界危机篇）**：境外魔人联合势力侵略日本本土，作为国际魔法骑士联盟日本分部最高军事指挥官坐镇中枢，展现铁血救国担当，全面调动国家级资源支援一辉与史黛菈作战。
- **类别**：国际魔法骑士联盟日本分部部长 / 黑铁宗家当代当主 / 一辉·王马·珠雫之父（与长子王马已决裂断绝关系、视次子一辉若路石） /〈铁血〉
