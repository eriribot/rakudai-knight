# 紫乃宫天音 / 天宫紫音（Shinomiya Amane / Amamiya Shion）

- **人物 ID**：`char-amane-shinomiya`
- **显示名**：紫乃宫天音
- **别名/触发词**：紫乃宫天音、天宫紫音、天音、恶无常、厄运、女神过剩之恩宠、蔚蓝、死神之手、因果干涉、Shinomiya Amane、Amamiya Shion、Nameless Glory、Bad Luck
- **首次出场**：第五卷第一章（晚宴交流会登场）
- **系列关键出场**：
  - 第五至六卷：以诡异的不战而胜连克强敌，在 D 区逼退药师雾子；
  - 第七卷末：地下准备室遭黑铁珠雫与有栖院凪奇袭，反杀重创二人并将珠雫钉在墙上；
  - 第八卷第十一章至第十三章：揭露真实姓名天宫紫音与残酷身世，准决赛伪装弃权被一辉叫破，正赛遭一辉〈一心刀〉与心跳复苏击破；赛后暴走施展「死神之手」袭击主审，被一辉以〈一刀修罗〉及第二秘剑〈裂甲〉彻底制伏，送医认罚；
  - 第八卷间章：病房面对西京宁音立誓不插手决赛，接受联盟处分。
- **类别**：国立晓学园一年级正选代表／A 级骑士／因果干涉系破格绝顶／曾挂名〈解放军〉

   - 恰逢金融风暴爆发，母亲投资炒股瞬间巨额亏损、负债累累。绝望疯狂的母亲将他锁进兔子笼中施以长达半年的残酷虐待与皮开肉绽的毒打，不断逼问：“希望我住手的话，就让我幸福！”

> *“母亲的答案总是如此。——希望我住手的话，就让我幸福。……于是，这样的地狱持续了半年左右——天音终于开始恨起母亲，而命运一如往常地回应着天音的心。‘紫音，没事吧！？太好了，还来得及，真是太好了……！’一名中年男子浑身染上母亲的鲜血，将濒死的天音从笼中救了出来。他隐约还记得，眼前的男子就是自己的父亲。……露出和母亲一样的笑容，这么说道：‘所以——你以后爱着爸爸就好。’就在这个瞬间，天宫紫音明白了一切。这个世界……不需要天宫紫音。”（L4833–L4867）*

### 4. 正式比赛未使用一刀修罗即获胜（第十三章）
