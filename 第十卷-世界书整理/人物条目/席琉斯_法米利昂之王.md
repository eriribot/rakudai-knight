# 席琉斯·法米利昂（Sirius Vermillion / 法米利昂国王）

- **人物 ID**：`char-sirius-vermillion`
- **显示名**：席琉斯·法米利昂
- **别名/触发词**：席琉斯·法米利昂、席琉斯、法米利昂国王、席琉斯王、红莲狂狮、狂狮岳父、狂狮、Sirius Vermillion
- **首次出场**：第十卷第三章（飞扑史黛菈未遂咆哮登场，L1498-1514）
- **系列关键出场**：
  - **第十卷**：初登场。极度溺爱幼女史黛菈的重度女儿控。因在电视转播中见一辉刺穿史黛菈腹部而当场口吐白沫、昏迷三天；醒后咆哮欲调动军队向日本宣战；瞒着妻女私调 50 名亲卫队并发布全城高额悬赏通缉令阻截一辉；在王宫餐厅企图以“长女露娜艾丝不在”推脱，被露娜艾丝当场抓包；被按跪在大理石地板上，遭阿斯特蕾亚狠扭耳朵痛嚎求饶，遭露娜艾丝后跟踢击中头顶；最终在露娜艾丝全境广播与民意倒逼下立下代表战军令状。
  - **第十三卷至第十五卷**：第一章中央公园石阶豪饮拦下一辉，散发高热杀气挥出巨岩重拳，严厉质问后立下君王与武人重诺：“用手中的剑让孤闭上嘴！”；第三章温柔抚摸长女秀发揽下国家重担：“怎么能把国家的重担压在女儿的幸福之上！”；第十四卷忧虑西京宁音的魔人鬼角；第十五卷亲率卫队奔赴奎多兰前线以肉躯化作生体盾牌保护一辉与珠雫；病房抓狂被阿斯特蕾亚掐臀痛呼。
  - **第十九卷**：视讯会议因美方干预大怒被约翰国王拖走，后向黑铁严表达深厚信任；终章傲娇主礼见证一辉与史黛菈大婚。
- **详尽全量考究出处**：参见 [席琉斯_法米利昂.md](file:///d:/card/rakudai-knight/人物仔细考究/席琉斯_法米利昂.md)
- **类别**：法米利昂皇国现任国王／史黛菈与露娜艾丝之父／C 级伐刀者／前线护民铁血雄狮

## 卷内核心阴谋与霸者担当

1. **私调军队与全城悬赏（第十卷第三章）**：
   席琉斯自七星赛得知一辉与史黛菈交往后便心生嫉恨，无法接受亲手抚养长大的宝贝女儿被外国穷小子抢走。卷十中瞒着王后与长女，暗中动用国库签发高额悬赏令，并出动皇室亲卫队 50 人与城防军队在皇都布下天罗地网阻截一辉。
2. **大理石地板弹劾与认同妥协（第十卷第三章）**：
   露娜艾丝掌握通缉令物证当场人赃俱获，席琉斯被罚跪在大理石地板上遭全家三位女性严厉审判与弹劾（遭阿斯特蕾亚扭耳痛呼、遭露娜艾丝后跟踢砸头）。但在亲历一辉真情求婚后，内心深处已被一辉超越阶级的气度、武艺与对史黛菈的真挚爱意深深折服，半推半就承认了“五年一度代表战取胜则允诺婚事”的约定。
3. **前线肉盾与主礼大婚（第十五卷、第十九卷）**：
   第十五卷亲赴前线以肉躯充当生体护盾掩护一辉；第十九卷终章与黑铁严共同主礼，虽然嘴上依然傲娇抱怨，但满怀骄傲与热泪见证了爱女与一辉的世纪婚礼。
