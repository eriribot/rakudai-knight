# 设定条目：法米利昂与奎多兰五年一度代表战机制

> **所属范畴**：国际魔法骑士联盟地缘政治条约 / 领土争端裁决制度  
> **涉及国家**：法米利昂皇国 (Vermillion Empire) VS 奎多兰王国 (Kingdom of Kledelland)  
> **核心争端标的**：两国国境交界处之高价值**天然气田所有权**  
> **周期与赛制**：每五年举行一次，本届确定为**五对五魔法骑士团体战（五场三胜制）**  
> **历史胜负背景**：过去整整三十年间，法米利昂皇国未尝一胜  
> **世界书 / 跑团触发词 (Trigger Words)**：`法米利昂与奎多兰代表战`, `代表战`, `领土代表战`, `天然气田争夺`, `特别征召`  

---

## 一、 联盟代表战条约的历史渊源与法律效力

在《落第骑士英雄谭》世界观中，中小国家为了在大国林立（如美、俄、中组成的大国同盟）的国际压迫下自保，联合组建了〈国际魔法骑士联盟〉。为杜绝加盟小国因内讧爆发毁灭性的全面正规战争，联盟主导人〈白胡公〉亚瑟·布莱特主导确立了核心条约：

```text
┌─────────────────────────────────────────────────────────────┐
│ 【联盟加盟国战争裁决宪章】                                    │
│ 1. 绝对禁止加盟国之间动用常规军队、热兵器与大规模杀伤性武器； │
│ 2. 一切国家领土、资源与主权争端，必须委任各自代表骑士决斗；   │
│ 3. 以裁决场上的胜负结果，作为终审国际法裁决依据；             │
│ 4. 确保弱小国家亦能凭借少数顶级骑士与大国维持对等尊严。       │
└─────────────────────────────────────────────────────────────┘
```

## 二、 法米利昂与奎多兰的百年恩怨与演习默契

### 2.1 独立战争与领土争端
数百年前，法米利昂地区原为奎多兰王国的一部分。后因不满奎多兰统治者的暴政，当地人民拥立势力最大的温和派贵族“法米利昂公爵”发动独立战争，割据建国。自此两国国境附近的丰富资源矿区与天然气田成为百年摩擦之源。

### 2.2 变相的五年和平联欢与公共补贴（战前默契）
名义上代表战赌注巨大，但数十年前两国高层定下补充条约：**战胜国在获取气田收益后，必须以援助金的形式反哺战败国内的公共设施维护费用**。
因此，在第四章惨案爆发前，两国代表战实际上已经演化为“五年一度的两国精英公开演习兼国民联欢会”，双方甚至乐见彼此互利，奎多兰国王亦因此大度批准了外国籍一辉的“特别征召”。

## 四、 战争质变：从体育演习到国家存亡血战

第四章欧尔·格尔突降路榭尔集训场，将奎多兰全员灭门并布设〈人偶王国〉，彻底撕毁了两国百年来保持的绅士默契。法米利昂代表战骤然由原本“考核一辉的和平考核场”，暴烈质变为阻击跨国恐怖主义与魔人亡国入侵的生死前线。
