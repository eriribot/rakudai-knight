# Asterisk Chapter Summary & Worldbook Anti-Hallucination Workflow

本技能完整沉淀自 `DLC/学战研究/第一卷-世界书整理`（尤其是第一章试点总结与全卷纠错）的实战经验，用于将用户在分章精读 `.md` 中留下的 **读者评注/备忘** 与 **原著第 1～17 卷正典、动画官方设定图** 结合，标准化产出无幻觉的章节事实索引、人物条目、设定词条与分章场景世界书。

---

## 一、 七大核心红线铁律 (Non-Negotiable Red Lines)

1. **战力上限与禁伪造六维红线（`学战上限 << 落第`）**：
   - 《学战都市Asterisk》战力上限远低于《落第骑士英雄谭》。
   - 《学战》原作**不存在**《落第》破军壁报的「六维属性（A/S/EX）」与「伐刀者等级」，**严禁**在《学战》人物正文中编造六维面板或强行拔高对标《落第》高阶伐刀者。
2. **外观「动画人设优先」+ 机制「全卷原文核验」双轨制**：
   - **视觉外观（服装、发色、面部特征、官方英文名）**：严格以 **TV 动画官网设定图与游戏立绘** 为准，严禁凭职业身份自由发挥（如禁止凭“女教师”脑补西装套裙、禁止凭空给塞拉斯加眼镜、禁止保留动画已删去的夜吹英士郎左脸伤疤）。
   - **身高数值**：未查得官方公布厘米数时，只写原文体态（如“身形修长”、“比绫斗高出一个头”、“身高接近两公尺”）并注明 `未查得官方具体身高数值`；若采用游戏立绘同框比对估算值，必须注明 `（据游戏画面推测，非官方公布数值）`，严禁断言为官方数据或串用他作身高。
   - **招式、武器与悬疑真相**：必须检索本地第 1～17 卷 EPUB 原文核实，严禁自造招式名（如禁止给匡子无名钉刺能力编造「封钉复写」）、严禁跨卷乱塞幻觉招式、严禁搞混悬疑栽赃主次（如第一卷持斧壮汉与矮胖十字弓手全系塞拉斯操纵假扮雷士达与兰迪的无机物人偶，雷士达与兰迪本人从未偷袭）。
3. **不确定项「先汇报、不入正文」铁律**：
   - 凡遇到疑似脑补、版本出入（小说 vs 动画 vs 特典小说）或缺乏直接原文依据的细节，**必须先在对话回复中向用户列出确认，绝对禁止直接写进 `<...>` 世界书正文冒充正典**。
4. **「防截胡」真义（仅禁元词汇污染）与严禁“摄像头/纯看客”窒息限制**：
   - **字面禁绝（元词汇防污染）**：所谓“防截胡”，**仅指绝对严禁在世界书正文（XML 标签内外）中出现『截胡』二字及类似网文打卡元词汇（如『截胡点 A』『截胡剧本』『防截胡』）**。出戏的元词汇一旦写入提示词，会导致 LLM 频繁出戏复读或把角色互动打卡机械化。
   - **绝对严禁剥夺玩家能动性（坚决封杀“摄像头/纯围观/严禁干涉”反模式）**：
     - **“防截胡”绝不等于“不让玩家干预或截胡事件走向”**！玩家（`{{user}}` / 自定义角色 OC）拥有完全的角色扮演主动权与沉浸式自由度。
     - **严禁**将自定义角色写成“场外目睹二人真挚情感羁绊”、“严禁参与地下战斗”、“只能在柱子下呼叫脱困”、“严禁上前打扰二人修行”、“仅可作为场外见证者记录剑理”等无能狂怒的**场外摄像头/纯路人背景板**！这彻底违背了 SillyTavern 跑团互动与沉浸扮演的本质。
   - **高能动性交互路由与分支设计原则**：
     - 在场景条目的【自定义角色模式 / 多维交互路由】中，必须为玩家设计**高参与度、强互动感、有战术或情感价值的介入空间**：
       1. **并肩突破与战术分流**：可直接加入战斗、迎战侧翼强敌、牵制怪物群为同伴争取蓄力时间、或实施武装破译与反制；
       2. **应急救援与关键支援**：递送备用武装/恢复物资、展开防御障壁掩护伤员、破译终端漏洞提供撤退通路；
       3. **社交破冰与情感互动**：在日常或名场面中主动拼桌调侃、递冰饮解辣打圆场、与角色进行平等而鲜活的人格碰撞；
       4. **平行破局与改写走向**：若玩家能力和策略足够，完全允许玩家凭借合法行动改写局部战况或提前化解危机，形成充满张力的平行分支，而非被原著剧情按头当看客。
   - 人物条目统一编写 **【泛用交互指南与情绪触发机制】**，聚焦三大泛用准则：
     1. **为什么生气 / 雷点逆鳞**
     2. **为什么高兴 / 加分喜好**
     3. **为什么害羞 / 破防 / 认怂 / 动心反差**
5. **可攻略女角色「全卷切片 + 商讨定调」机制**：
   - 对可攻略女角色（尤其班导、学姐、对手等恋爱线较隐晦的角色），先检索第 1～17 卷及特典小说补全完整经历，提炼原文语句与性格切片在对话中与用户商讨方案（如匡子 A 江湖大姐头 × B 私下生活白痴反差），敲定后再写入正文。
6. **Token 与中文字数分级硬约束 + XML 零代码污染**：
   - **女角色**：SillyTavern 估算 Token 严格控制在 **`3,000–4,500 Token`**（重点跨卷核心女角色推荐 `3,500–4,500 Token`，XML 中文字数约 `2,850–4,100 字`），必须严格大于男角色；跨卷补充内容须明确标注 `【原作后续卷补充】`。
   - **男角色**：SillyTavern 估算 Token 严格控制在 **`2,000–2,500 Token`**（边缘跟班配角约 `1,800–2,200 Token`，XML 中文字数约 `1,600–2,360 字`）。
   - **XML 洁净度**：`<...>` 标签内部**严禁出现 `CH-01`、`#L123` 等章节行号引用**（行号索引只允许出现在章节总览索引表或 YAML 事实锚中）。
7. **排版格式洁净度红线（全量严禁 `***` 符号）**：
   - **绝对禁止 `***`**：在所有世界书条目（XML 内外）以及章节整理文档中，**绝对严禁出现任何形式的 `***`**（无论是用作分割线、场景切分线、加粗斜体 `***text***` 还是装饰符）。
   - **禁绝原因**：SillyTavern 前端会将 `***` 解析渲染为突兀难看的粗横线（`<hr>`），且极易污染 LLM 提示词上下文，诱导大模型在后续对话生成中频繁复读多余的 `***` 分割线，严重破坏阅读排版与沉浸感。
   - **替代规范**：段落层级与分类一律采用标准的 Markdown 标题（`#`、`##`）、方括号标头（`【...】`）或列表（`-`、`1.`）；章节场景切换使用明确的场景标签，完全禁用 `***`。

## 二、 标准执行流程 (6-Step Chapter / Volume Summary SOP)

当用户指示按本技能推进下一章（如 `第一卷_02_第二章_学战都市.md`）或下一卷（如 `第二卷`）时，严格按以下步骤执行：

### Step 1：扫描读者高亮标记、行内批注与本章全量盘点
1. **一键提取 Obsidian 原文高亮与批注**：优先运行高亮与批注提取脚本，精准收集用户在目标章节（如 `第二卷_01_第一章_六花园会议.md`）中划出的全部 `==高亮原文==`、多色 `<mark>` 标签、紧随其后的 `%%行内胶囊批注%%` 以及分幕/章末评注卡（自动带出幕次与 `#Lx` 物理行号，**严禁修改或删除用户写下的原始高亮与批注**）：
   ```powershell
   $env:PYTHONIOENCODING='utf-8'; python .agents/skills/asterisk-worldbook-workflow/scripts/extract_reader_highlights.py "DLC/学战研究/第二卷-世界书整理/第二卷_01_第一章_六花园会议.md"
   ```
2. **盘点本章出场人物、设定词条与场景节点**：
   - 新登场有名字角色 $\to$ 列入新建 `人物条目/` 计划（不漏跟班、导师、幕后角色）。
   - 已建档角色在本章展露的新语句、新性格侧面或伏笔回收 $\to$ 列入既有 `人物条目/` **增量精修**计划（重算字数确保不越界）。
   - 新学园/企业财团/武装/规则设定 $\to$ 列入 `词条与设定条目/` 新建或补充计划（**大教授×大博士「北关东日光湖域闭关样本＋每月异界物资与有限返乡画饼」仅维护在独立联动世界观词条中，严禁写入角色个人动机**）。
   - 本章时间（并列至 **2013 年初夏**且星期几严格对齐）、地点链、三幕推进与**章节完成标识（Completion Trigger）** $\to$ 列入 `场景条目/` 新建或核验计划。

### Step 2：多源交叉考据（全 17 卷 EPUB + 动画设定图 + 插图台账 + 百科）
- 检索本地 `DLC/` 第 1～17 卷 `.epub` 原文语句，对照 `DLC/学战研究/插图/`、`05_插图OCR全量台账` 与动画官网/权威百科，核实外文名拼写、动画服装配色款式、武器全称、招式白名单与特典前史。
- 对照参考文档中的 10 大历史踩坑案例逐项排雷：[volume1-pitfalls-and-templates.md](./references/volume1-pitfalls-and-templates.md)。

### Step 3：存疑项汇报与角色性格商讨
- 若发现小说与动画外观冲突、缺乏官方具体数值、或涉及可攻略女角色性格演绎方向，**先在回复中列出原文证据与选项供用户拍板**，绝不擅自写入 `<...>` 世界书正文。

### Step 4：产出/更新章节总结索引与世界书条目
1. **章节世界书整理总览与事实来源索引**（如 `02_第二章_世界书整理总览与事实来源索引.md`，及按需生成的 `AIRP/CH-0X/` 事实锚与事件图 YAML）：
   - 按 `extracted`（本章明文事实，附 `#Lx-Ly` 行号回指）、`foreshadow`（本章伏笔，防提前剧透）、`crossover_canon`（双界融合底层法则）三级建立「读者批注 $\leftrightarrow$ 原文行号 $\leftrightarrow$ 目标世界书文件」映射表与时间线小节拆解。
2. **撰写或增量精修 `人物条目/`、`词条与设定条目/`、`场景条目/`**：
   - 严格按照 [volume1-pitfalls-and-templates.md](./references/volume1-pitfalls-and-templates.md) 的标准 XML 骨架落盘，区分「当前阶段已知」与「`【原作后续卷补充】`」。
   - **场景条目能动性铁律**：【自定义角色模式】必须提供真正具备行动力与参与感的高沉浸介入分支（如战术并肩突击、侧翼阻击牵制、关键道具支援、名场面主动破冰），绝对严禁写成无能围观的“场外摄像头/禁止干涉的背景板”。
3. **回填章节 `.md` 底部工作区索引**：
   - 在保留用户原始批注不变的前提下，于章节底部的整理工作区补充指向本章索引与相关世界书条目的 Obsidian 双链。

### Step 5：运行自动化审计脚本（强制门禁）
每次创建或修改完任何世界书条目后，**必须**运行本技能自带的校验脚本：

```powershell
$env:PYTHONIOENCODING='utf-8'; python .agents/skills/asterisk-worldbook-workflow/scripts/audit_worldbook_entries.py "DLC/学战研究/第一卷-世界书整理"
```
（若整理后续卷目录，将参数替换为对应目录路径。）

### Step 6：清零告警并交付统计报告
- 确保脚本输出 `PASSED`（女角色 `3,000–3,500 Token`、男角色 `1,800–2,500 Token`、`女 > 男`、XML 内零 `CH-`/`#L`、零 `截胡`、零伪造 `六维属性`、全量零 `***` 符号）。
- 向用户汇总新增/更新文件链接、字数与 Token 审计表，并单独说明已拦截未入正文的存疑项。
