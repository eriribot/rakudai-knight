# 设定条目：史黛菈的龙之力（第六卷可知边界）

- 关键字：史黛菈、巨龙幻影、暴龙咆吼、龙之力、特训成果
- 使用时点：四对一龙影与咆吼已经出现后，或赛后讨论尚未揭明的特训成果。
- 命名限制：文件沿用“龙之力”作为检索标签；第六卷未给它一个完整、已揭露的正式机制。

```xml
<第六卷_史黛菈的龙之力>
【本卷实际展示】
- 史芬克斯面对史黛菈的咆哮，感到她是远强于自己的掠食者，仿佛看见少女身后的擎天巨龙；它因此甩开风祭逃跑。
- 史黛菈动用暴龙咆吼前，所有在场者都见到比瓦砾巨人还庞大的红莲炎龙影像。叙述明确说明那不是实体，而是魔力高涨、威严引发的幻觉。
- 不把视觉威压写成召唤真龙、身体变龙、独立灵魂或已经揭露的龙神附体。

【暴龙咆吼】
- 本卷常用招名〈暴龙咆吼〉；个别叙述写作〈暴龙咆哮〉，在此视为同一招，不造两项独立技能。
- 它是把魔力瞬间输出提升到极限、全方位释放的高热暴风，施法迅速，难以精确控制。潜在射程覆盖海湾巨蛋和周边鬼城，明显超过直径约百米的战圈。
- 幻想形态免除人体物理伤害，仍会消耗体力、令人昏迷，也不会保护建筑。史黛菈须依赖第三者防护，才可避免毁坏观众席和设施。
- 本场王马最先以风墙卷起暴风，其余驻场骑士迅速布设多层屏障，限制本次实际影响；主审仍在场内被卷入昏厥。
- 她原本不愿在荣耀决斗中使用需借他人力量的手段。平贺拿美琴为人质后，她将战斗视为扫除，改用此招，并测试运营方能否接住她的全力。

【与特训成果的区别】
- 一辉明确认为暴龙咆吼在刚入学不久就能学会，黑乃也指出这类不控制输出的招数不需要特别特训。
- 西京一周修行带来的可见成长，包括信心、死角警觉、敏锐反应及愿意信赖周围人的防护。
- 一辉从史黛菈重新振作、期待再战的气魄，推测她还有更强的成果尚未亮出；本卷没有揭示那项成果的正式名字、原理或代价。

【相邻机制不要混写】
- 初段夹击无伤源于庞大魔力屏障；多多良反射仍粉碎左腕，夏洛特再折上臂。火焰熔接碎骨恢复举剑，不是龙形态赋予的自动再生。
- 龙王炎是超过五十公尺的光热巨剑，可连续施展十二次；暴龙咆吼则是全方位输出，两者不是同一招。

【知识可见性与开放应用】
- 初次龙影属狮子的感受，随后高涨威严使全场看见幻影；不让人类提前共享野兽内心画面。
- “还藏着更强成果”属于赛后一辉的推断；不要让未听谈话的人自动知道，也不将推断当具体能力事实。
- 玩家可改变安全辅助、输出、逃避或信任关系；若没有可靠防护，不自动获得原著清场而观众无伤的结果。
</第六卷_史黛菈的龙之力>
```
