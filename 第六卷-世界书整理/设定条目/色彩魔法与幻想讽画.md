# 设定条目：色彩魔法与幻想讽画

- 关键词：色彩魔法、幻想讽画、德米奥格之笔、湖面之水蓝、烈焰之火红、引导之纯白、钢之青铜、死灵大军、无冕剑王
- 时点：〈色彩魔法〉为莎拉旧资料所载能力；〈幻想讽画〉在本卷 C 区第二轮第一场首次公开。
- 来源：第六卷正文 L5733–6617。仅列本卷现场证据，不拼入第七卷设定。

## 可复制的世界书 XML 正文

```xml
<SaraColorAndFantasyVolume6>
【能力主体与揭示层级】
- 使用者为莎拉·布拉德莉莉，灵装〈德米奥格之笔〉由老旧画笔与颜料调色盘构成。
- 禄存时期公开资料称她操纵与色彩有关的概念，等级为 C，称号〈万花筒〉。第七章公开〈幻想讽画〉后，众人才知道能力亦涉及图画概念与具现。
- 色彩与图画是本卷明确描述的能力范围；解说的战力推断必须与已验证的具体效果分开。

【色彩魔法：本卷四种明确效果】
- 湖面之水蓝：让着色的战圈具有水、湖面的性质；莎拉潜入其中，在战圈内游走，从藏人背后跃出。不能改成无条件瞬移或任意距离传送。
- 烈焰之火红：在着色处产生热与火焰，现场颜料如岩浆般喷火并溶解战圈。需要按实际着色与命中判断，不能自动必中。
- 引导之纯白：白色道路具有引导概念，踏上者无法越过色彩道路。藏人不能向侧面离开，却仍可沿路前进，不是全身定身。
- 钢之青铜：本场使莎拉着色的左臂化为钢铁，挡住藏人的斩击。没有全身永久金属化、铜毒或恢复伤势的展示。

【幻想讽画：图画概念与实际具现物】
- 莎拉在空中快速作画，让画成为立体并来到现实。汤姆森冲锋枪与真品一样能射击，藏人以缩短双剑挡下弹雨；停火时他判断已经没有子弹。不能把具现枪写成无须弹药的无限攻击。
- 地面的标的图案具有猎物概念，强制把〈大蛇丸〉的攻击目标改为标的；这是图画概念效果，不是〈神速反射〉失灵，也非莎拉躲避速度突增。
- 战斧巡弋飞弹具现后爆炸，藏人以伸长双剑缠成的白茧防空洞挡住。死灵大军由上百名骸骨和军用机枪构成，弹幕被〈天衣无缝〉卸除，骸骨随后被长剑横斩。
- 坦克、战斗机、巨大机器人未实际出现，只存在于藏人“无论再画出什么都要斩碎”的假设中。

【无冕剑王复制体与本卷验证范围】
- 〈幻想讽画〉具现出手持黑刀的一辉复制体，可重现〈一刀修罗〉及当前〈比翼之剑〉。复制体把藏人逼入守势；诸星根据此前亲自交战经验，认为技巧、头脑、洞察力与真人相同。
- 藏人以双剑十六连斩斩碎一名，随后两个新复制体贯穿他。莎拉能反复绘出多个复制体；本卷没有给出数量上限、消耗公式、存续时间或绝对无限的结论。
- 牟吕渡据此推断她能够使用所有伐刀者的能力、没有死角，并认为她实力相当于 A 级；这是解说面对已展示能力的评价，不能提升为无条件复制所有人的已验证规则。

【角色知识与玩家状态】
- 第七章此招第一次在公众面前展示，之前的公开资料没有它。只有亲见对应效果、被告知或有独立可靠证据的角色可以知道其细节。
- 以当前存档记录已展示颜色、所画对象、命中、应对与魔力消耗；不由原著胜负替代当前交锋结算。
- 本卷没有发布完整能力说明。对于未展示的颜色、图案、人物或技法，按剧情中得到的证据处理，不凭名称自由追加功能。

【禁止误写】
- 禁止混淆色彩效果与图画具现；标的不是纯白引导道路，青铜防御不是治疗。
- 禁止把具现复制体写成真一辉本人被瞬移到场，也不强迫复制体继承未出现过的后续剑术。
- 禁止以本卷内容宣布官方已改 A 级，或擅造无限军队、无限魔力、固定复制冷却与战力百分比。
```
