# 设定条目：反射术士与完全反射（第六卷）

- 关键字：反射术士、完全反射、多多良幽衣、不转、反弹
- 使用时点：讨论攻击返还的相性、判断多多良反射是否触发及其破解方式。

```xml
<第六卷_反射术士与完全反射>
【类别与具体技能】
- 〈反射术士〉是将来袭攻击反射回去的能力类型；第六卷明确以多多良幽衣的伐刀绝技〈完全反射〉展示此能力。
- 完全反射能将冲击或损伤反弹；敌方越强，其原本攻击被返还时越危险。别把这写成与敌方无关的自生攻击力加成。
- 多多良在身体外侧布下“反弹”概念结界，扭转来袭斩击向量；又能瞄准接着来的拳头再发动一次反射。

【察觉与发动】
- 高速隐藏剑路、在施术者察觉前击倒，理论上可使其来不及发动。第六卷回顾一辉曾以此破解微笑，但两人能力相似不代表反应能力相同。
- 多多良从三岁起经历父亲持续暗杀，练成极强动态视力与集中力；可识别枪林弹雨中的子弹，也能看清一辉此前模仿爱德怀斯的剑影。一般高速斩击并非可靠保证。
- 本卷没有把反射写成无意识常驻、全自动防御，也没有给魔力消耗、冷却或固定次数上限。

【伤害与破解实例】
- 史黛菈用轻右斩作诱饵，借其被反射后的后仰与身体转动出左拳；多多良看穿了这套连动，确实反射两次。
- 左腕遭反射粉碎后，史黛菈并未停下，而在多多良确认得手、松懈的瞬间继续转踝施力，用碎拳重击侧腹、使其昏迷。
- 因此“反射成功”不等于“对手已丧失攻击能力”。这次失败来自多多良对对手承伤后行为的漏算，不是反射失效、被更高魔力取消或被速度骗过。

【射程与方向边界】
- 第六卷仅明确身体外侧结界及返还来袭向量的近身实例；未给最大射程数字，也未规定可自由把攻击改射向任意第三者。
- 不把“反射所有攻击”的类别概述扩大成反射概念、时间、精神、命运或远处任意攻击的无限权限。
- 也不凭未提及规则反向编造固定角度、只能原路反弹或特定半径。此卷不足以决定的细节保持未知，裁定时需要其他已验证依据。

【知识与开放应用】
- 间章先由彼方的交战经历证实多多良是反射术士；赛场解说再根据首轮表现和实际战斗逐步解释。
- 角色只可使用已经获知的情报。玩家可改变诱攻、节奏、掩护和承伤后的动作；不能因原著拳击取胜，就默认每次都能用蛮力穿过反射。
</第六卷_反射术士与完全反射>
```
