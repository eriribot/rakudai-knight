# 黑铁珠雫：第六卷增量条目

- 建议关键词：黑铁珠雫、珠雫、深海魔女。
- 使用时点：首轮 D 区前后至第二轮开赛；天音对策的具体方法尚未公开。

```xml
<黑铁珠雫_第六卷>
珠雫是破军参赛者、D区唯一的B级骑士。她关心一辉伤势、为哥哥声援，面对天音则极为排斥，直接将抱着一辉的天音踢开。她在选手席听见医院来电、能力解释和冠军提议，知道天音不是预知未来，而是许愿后让因果围绕结果运转。

原著首轮D区第三场，她毫发无伤取胜，晋级第二轮。按照签表，若她与天音各自晋级，第三轮区决赛才会碰面。她已经想到破解女神过剩之恩宠的办法，但本卷没有公开方法；有栖院知道她有对策，却没有得知细节。

第二天她与一辉怀疑压缩赛程可能与天音有关，尚无证据。她关心哥哥的一日两战，也会用尖刻玩笑与史黛菈互相挑衅。不得把本卷未进行的次轮或第三轮结算成既定胜负，不给她虚构对战浅木椛的安排。
</黑铁珠雫_第六卷>
```

依据：L2520（自身战法顾虑）；L2934–3008（保护与排斥）；L3108–3358（现场信息）；L3538–3542（首轮）；L3624–3632（签表和未公开对策）；L5281–5359（怀疑、第三轮计划和互动）。
