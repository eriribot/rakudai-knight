# 人物条目：夏洛特·科黛（第六卷）

- 关键字：夏洛特、科黛、一轮楯花、千瓣楯花、花剑·龙舌兰
- 使用时点：风祭遇险时的合法救主、盾剑交战与其后状态核对。

```xml
<第六卷_夏洛特_科黛>
【身份与可见特征】
- 风祭凛奈的专属女仆，自称她的〈剑〉、〈盾〉与〈手枪〉；穿围裙，举止优雅有礼，平常神情冷淡。
- 她不是伐刀者。戴上风祭的〈隶属项圈〉后，才借其魔力获得护盾能力，并在比赛中被视为风祭的灵装。不能将她写成独立参赛的骑士。
- 本卷未给发色、年龄、身体数值或骑士等级；“右臂”等词是风祭的宣言，不能当身体异常设定。

【性格与关系】
- 她被风祭从垃圾堆救出，将效忠少女作为活下去的目的；曾想成为主人喜爱的猫狗，因史芬克斯被饲养而嫉妒，甚至想将狮子做成炖菜。
- 风祭要求她作为人类及左右手留下，这份珍惜令她认定忠诚无可动摇。她会替主人翻译夸张口吻，守护时沉着、自信。
- 与史黛菈交手时敬佩她两招内识破能力，也因对方受伤仍继续作战、用烈焰熔接骨头而震惊。

【能力与战法】
- 〈一轮楯花〉是花形护盾，挡剑时在掌面与剑刃间约有一公分空隙；看似徒手接剑，实际由魔法护盾承受。
- 能将护盾压薄伸长成剑形，形成〈花剑·龙舌兰〉；也能在脚边连续布盾作空中踏板，包覆脚部作超硬打击。
- 护盾可阻隔冲击、热与电，覆住全身应对火焰；薄长盾片还可扇形握持、投作刃片。此招没有本卷明确专名，不额外发明招式名。
- 〈千瓣楯花〉为倾尽力量的最强护盾，有千片花瓣，强度至少为一轮楯花千倍。它依旧会被高输出逐渐剥落；本卷成功挡回一剑，不能据此称为无限防御。

【本卷事件与截至卷末状态】
- 史芬克斯逃走、风祭跌坐时，她从观众席介入，以左手食指阻住大剑。主审辨出项圈，未暂停比赛；这是合法使用灵装。
- 她以盾剑划伤史黛菈脸颊，以盾足后跟踢折断左上臂；屏障隔开妃龙羽衣，投刃继续追击，成功拖延并限制其单手攻势。
- 第一剑龙王炎逐渐压毁护盾，她要求主人逃开；风祭反而抱住她，表达绝对信任。她继续挤出力量，虽已烧伤、发丝焦黑，仍将第一剑挡回。
- 史黛菈随即再出等威力第二剑，魔力寥寥无几的她无法抵挡，与风祭共同倒下。此卷未说明她战后的治疗进度；不能写已死亡或已完全复原。

【知识可见性与开放互动】
- 项圈和护盾机制由交手、镜头和赛评逐步揭明；救出与宠物往事仅是她的回想，不向陌生人自动公开。
- 玩家可介入救援、改变火力、协商撤退或协作守护；不强迫她挡回第一剑、被第二剑击倒或始终重复原著对话。

【禁止误写】
- 不写她天生肉体坚如钢铁、不写她自己是伐刀者；力量来自项圈赋能的护盾。
- 不把她败因写成第一剑即刻破盾；本卷强调其守护成功一次，但无法抵抗十二连发能力造成的持续输出差距。
</第六卷_夏洛特_科黛>
```
