# 人物条目：仓敷藏人（第六卷）

- 时点：第七章红门准备室至 C 区第二轮第一场赛后；新双剑与师承按实际揭示时点加载。

<KuraudoVolume6>
【身份与本卷起点】
- 贪狼学园三年级，称号〈剑士杀手〉。少年袒露胸膛，胸口有骷髅刺青，言语粗暴，渴望战斗。
- 本卷回顾，他此前在绫辻绚濑相关事件中败给一辉。为再次挑战一辉，他进行了两个月修炼，来到七星剑武祭；一辉是他当前最在意的对手。

【双剑变化、师承与知情边界】
- 固有灵装〈大蛇丸〉是能够伸缩并改变剑路的白骨剑。本卷已变为形状相同的两把双刃剑，不再是过去单把、单边锯齿的形态。
- 一辉在红门准备室见到双剑，理解藏人以强韧意志、抛弃过去自我与苦修改变了灵装。看台上的史黛菈与加加美只有疑惑；有栖院与珠雫不了解此前绫辻事件，认为可能记错或原本藏有双剑。
- 藏人曾到绫辻道场下跪，恳求绫辻海斗收为弟子，经历严酷特训后学会〈天衣无缝〉。一辉在弹幕中的受流表现认出师承，不能让所有观众在比赛前自动知晓。

【本卷招式与具体反制】
- 〈神速反射〉是超人的反应速度，亦有足以跟上反应的行动速度；能迟出招而先行应对。它不是预知未来，也不保证身体动作跟得上任何瞬间加速。
- 〈蛇骨双刃〉：开场使双剑伸长，从二十公尺外攻向莎拉；本场叙述明确整个直径一百公尺战圈都在其射程中。
- 〈蛇妖〉：原先单手瞬间左右两斩，本场双手施展形成四连斩；他用它打碎火红颜料薄膜，再逐滴避开飞沫，沿纯白道路前冲。
- 对汤姆森近距离弹雨，他将双剑缩至匕首长度、运用旋转力挡弹；停火后用〈蛇骨刃〉伸长突刺，但被地板标的强制改变目标。面对战斧巡弋飞弹，他延长双剑包裹身体、组成白茧式临时防空洞。
- 绫辻一刀流奥义〈天衣无缝〉：感知力的流向，以极细微动作卸除攻击。本场配合神速反射卸除死灵大军的密集铅弹；这不是身体变硬或被击中后治疗。刀线刀路整齐划一的一流斩击仍可突破其受流。
- 〈蛇咬〉在受伤后用于左右同时反击，但被复制体挡开。〈八歧大蛇〉原为瞬间八连斩，本场双剑同时施展达到十六连斩，且剑路经海斗训练已不同于往昔。

【战斗意志与卷末状态】
- 莎拉绘出一辉复制体，连〈一刀修罗〉与当前〈比翼之剑〉都能重现，压过藏人的行动能力。他受伤失血，回忆拜师缘由，承认自己不愿追丢那个让他首次憧憬的背影。
- 真正的一辉在红门下方声援，藏人把担忧当作被小看，由强烈愤怒撑起短暂的超越极限瞬间；十六连斩斩碎一名复制体，随即被两个新复制体贯穿。
- 原著基线：主审中止比赛，莎拉胜；藏人失去意识，灵装从手中滑落，被担架运送离场。没有记载他死亡、伤势已痊愈、仍晋级或已与真一辉完成再战。
