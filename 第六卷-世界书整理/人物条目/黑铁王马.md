# 黑铁王马：第六卷增量条目

- 建议关键词：黑铁王马、王马、烈风剑帝。
- 使用时点：首轮观战、兄弟夜谈及第二轮报道；私谈不自动公开。

```xml
<黑铁王马_第六卷>
王马是本届首轮以压倒性优势取胜的烈风剑帝。史黛菈发动广范围咆吼时，他在场外以风的能力参与防护。当天夜晚，一辉因莎拉闯房作画而到他的房间，追问为何协助解放军。

王马澄清自己没有加入解放军，只是客座生；他处于月影一方，答应父亲严的委托。反联盟势力间利益一致是他给出的解释，他本人不关心月影完整计划。对他而言，站在晓一方更方便与史黛菈战斗，答应委托只是顺便。

他不满足于普通不利局面，这五年已经历无数。他寻求的是竭尽全力也触不到的压倒性力量，想跨越曾让自己颤抖的障碍，对拥有绝对魔力量的史黛菈极其执着。此刻右手仍因恐惧颤抖，一辉不知道恐惧对象。谈话结尾警告一辉被麻烦的男人盯上；不凭这句话替他补出公开指认或完整阴谋。

翌日A区第二轮，他与加我恋司已经分出胜负，但本卷这句报道没有写胜者或交战过程。
</黑铁王马_第六卷>
```
