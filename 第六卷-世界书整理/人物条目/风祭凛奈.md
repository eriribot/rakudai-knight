# 人物条目：风祭凛奈（第六卷）

- 关键字：风祭、凛奈、魔兽使、隶属项圈、史芬克斯
- 使用时点：四对一团队夹击、夏洛特介入与主仆守护、次轮弃权公告。

```xml
<第六卷_风祭凛奈>
【身份与表现】
- 晓学园一年级代表，称号〈魔兽使〉；本卷以骑着黑狮子史芬克斯的少女登场。
- 习惯把话说成漆黑右臂、忠臣等夸张宣言，夏洛特会替她转述平实意思；面对多多良的命令会反驳，但仍能按合作需要行动。
- 此卷未证实她的发色、身材数值与骑士等级，不自行填入。

【灵装与战术】
- 固有灵装〈隶属项圈〉能给动物或非伐刀者人类赋予伐刀者能力。受赋能者身上环绕她的魔力，在赛事判定中作为她操纵的灵装行动。
- 史芬克斯藉项圈操纵“停止”概念，以咆哮形成〈兽王威吓〉夺取目标行动；〈兽王行进〉用魔力加速猛兽的肉体突击。停止行动不等于停止时间。
- 夏洛特才是她真正的王牌，拥有护盾能力；不能把每一项女仆技法都写成风祭本人的徒手技巧。
- 本卷未给项圈数量、最大控制人数、距离上限或强制支配伐刀者的证据，不增补这些功能。

【主仆关系】
- 她曾在垃圾堆救出夏洛特，让女仆将自己视为活下去与效忠的对象；她也拒绝夏洛特为了当宠物而贬低自己，要求她作为人类和左右手相伴。
- 女仆濒临挡不住龙王炎时，她拒绝抛下对方，抱住其腰背，明确以最忠诚骑士的身份信任她。她不是只把夏洛特当一次性盾牌。

【本卷事件与截至卷末状态】
- 与多多良从死角夹击史黛菈，曾让其无法动弹并击出场；对方的魔力屏障却挡住了肉体伤害。
- 再次配合美琴的降温迟缓围攻，史芬克斯因史黛菈的掠食者威严恐惧，甩下她逃走；夏洛特及时救主。
- 她的支持令〈千瓣楯花〉再度振作，挡住第一剑龙王炎；随后与耗尽力量的夏洛特一起被第二剑击倒。史黛菈计为第二名参赛者败退，女仆不是第五名选手。
- 后续主动弃权；营运委员会收到她与多多良的弃权通知，B 区余下比赛取消。此卷未给两人的后续康复细节。

【知识可见性与开放互动】
- 项圈身份由镜头聚焦与赛评解释后成为公众信息；项圈赋能本身不等于观众知道她救出女仆的往事。
- 玩家可影响合作、保护、撤退或主仆间的选择；战斗条件变化时，不强制狮子逃走、两剑败退或主动弃权。

【禁止误写】
- 不把〈兽王威吓〉写成停时；不把史芬克斯逃走写成风祭主动驱散灵装。
- 她选择留下支持夏洛特；不能删成躲在盾后等待或漠视女仆牺牲。
</第六卷_风祭凛奈>
```
