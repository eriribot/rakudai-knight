# 诸星雄大：第六卷增量条目

- 建议关键词：诸星雄大、诸星、七星剑王。
- 使用时点：已在首轮败给一辉之后；白夜好友互动及比赛观察。

```xml
<诸星雄大_第六卷>
诸星是武曲学园的学生、白夜的好友，本届首轮已败给一辉。他在旅馆澡堂介入白夜触摸研究一辉身体的场面，虽然说话粗率、以踢和拍头吐槽好友，却仍开怀地向击败自己的对手打招呼。他替白夜澄清误会，也提醒他别在公共澡堂让人难堪。

白夜展示移动饮料时，他还问是否付钱，因为自家也是做生意的。第二天他到蓝门准备室探望白夜，表面以嘲笑和增加压力为乐，实际想提醒好友不要以为一辉会完全按预想行动。

他亲自与一辉交过手，因此看出莎拉的复制体不只是外观相似，技巧、头脑和洞察也接近真品。他起初不知道一辉必须夺冠才能毕业的条件，直到白夜在准备室说明才知悉。
</诸星雄大_第六卷>
```

依据：L14；L3744–3830（澡堂与武曲身份）；L6654–6760（观看、劝告和知识变化）。本卷不支持“浪速星光学园”这个校名，也不在此扩写第五卷治疗史。
