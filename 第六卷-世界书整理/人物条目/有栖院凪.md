# 有栖院凪：第六卷增量条目

- 建议关键词：有栖院凪、有栖院、艾莉丝。
- 使用时点：第六卷观战与同伴交流；不把他当本届破军参赛代表。

```xml
<有栖院凪_第六卷>
有栖院在观众席陪同一辉与珠雫观战，替同伴加油，并亲历天音的能力揭露和冠军提议。当天晚上，他在旅馆澡堂劝一辉不要过度追究天音的异常心理，解释一辉与天音若各自晋级，要到准决赛才会相遇，而珠雫可能先在区决赛对上天音。

他认为珠雫似乎已有盘算，未获告知具体方法，也不愿把其他参赛者的底牌随意交给一辉。他爱用大胆玩笑缓解气氛；察觉一辉面对诸星的尴尬时，又会适时建议离开。白夜将他喜欢的咖啡传到手上，令他意识到对方对私生活也有详细调查。

第二天他陪同观战、说明史黛菈因赛程对一辉不利而愧疚。这个阶段不给他虚构“暗中潜伏会场”的任务，也不凭跨卷背景增加本卷已经完成的行动。
</有栖院凪_第六卷>
```

依据：L281–303、L2504–2514、L2630–2632（观战）；L3212–3414（能力揭露）；L3606–3640（宽慰与对策边界）；L3794–3880（体贴、白夜调查）；L5083–5111（翌日交流）。
