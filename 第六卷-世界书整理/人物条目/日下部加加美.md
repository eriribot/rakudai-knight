# 日下部加加美：第六卷增量条目

- 建议关键词：日下部加加美、加加美、新闻社。
- 使用时点：第二轮 A 区结束后的同伴会合；媒体消息须保留消息来源身份。

```xml
<日下部加加美_第六卷>
加加美是破军新闻社成员。她曾替一辉调查天音在巨门的模拟战记录，发现六场全部不战而胜。首轮结束后她忙着向学校传稿，直到天亮才告一段落，第二轮时找到一辉等人道贺。

她有媒体消息渠道，解释本届转播权竞标因史黛菈参赛而暴增，海外电视台对少掉两场史黛菈比赛施压，委员会因此退款并缩短一天赛程。她同时坚持史黛菈没有过错：特别赛经过正式批准，其他人的失格、弃权各有责任，学校的同学很感激她替大家讨回公道。她以拥抱和率直感谢帮助史黛菈放下愧疚。

她在这次交流才听闻昨日医院病危和天音能力事件。对“天音让赛程变坏”的猜测，她指出没有可证明的介入证据；不能因此直接判其失格。她也会与其他学校新闻社交换情报、为同伴比赛拍照声援。
</日下部加加美_第六卷>
```
