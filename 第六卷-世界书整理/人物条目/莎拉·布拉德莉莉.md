# 人物条目：莎拉·布拉德莉莉（第六卷）

- 关键词：莎拉·布拉德莉莉、染血达文西、万花筒、玛莉欧·罗索、德米奥格之笔、色彩魔法、幻想讽画
- 时点：访房时揭示画家身份；第七章 C 区第二轮第一场首次公开隐藏绝技。两次揭示的受众不同。
- 来源：第六卷正文 L4486–4676、L5683–6649；仅写本卷已证实内容。

<SaraVolume6>
【身份、外貌与知情时序】
- 晓学园一年级，称号〈染血达文西〉；过去就读禄存，校内因多样的色彩能力被称为〈万花筒〉。本卷公开资料是 C 级，赛后牟吕渡判断她实力相当于 A 级、应更正等级；没有正式改级记录。
- 杂乱金发、浓重黑眼圈，穿着暴露而不顾旁人的目光。对比赛常显倦怠，却会因艺术身份受质疑而动怒。
- 对外画家名是玛莉欧·罗索。她在一辉与史黛菈面前出示签名，史黛菈凭皇宫收藏确认，认出她是从不公开真面目的世界顶级画家。这个身份不因私下坦白就自动成为观众常识。

【性格、动机与本卷关系】
- 对创作有极强执着，把一辉视为理想男性主体，急于观察和描绘；本卷明说她不要求成为一辉女友，不能把裸体模特要求直接改写成恋爱告白。
- 她把自己的单方面要求称作约定，一辉明确拒绝。访房时墙上出现门把、墙壁打开，她据此闯入；本段没有报出招式名。
- 她以为史黛菈与一辉绘制婚礼肖像为交换，令史黛菈改变阻拦态度。一辉随即逃走；本卷没有在此确认他已经完成模特工作，也没有确认画像已经交付。

【灵装与已展示能力】
- 固有灵装〈德米奥格之笔〉是一支沾染色素的老旧画笔，配有颜料调色盘。能力涉及色彩概念，并能以〈幻想讽画〉操纵图画概念、具现所画内容。
- 〈色彩魔法〉的本卷实证：湖面之水蓝让着色处如湖水，可潜入战圈游走；烈焰之火红在着色处产生热与火焰；引导之纯白令踏上者无法越过色彩道路；钢之青铜把本场受击的左臂化为钢铁。
- 〈幻想讽画〉在与藏人的比赛中首次公开，具现汤姆森冲锋枪、战斧巡弋飞弹、装备军用枪械的骸骨〈死灵大军〉与〈无冕剑王〉复制体。地上的标的图案也能用猎物概念强制改变攻击目标。
- 复制的一辉能使用〈一刀修罗〉并展示当前的〈比翼之剑〉技巧；诸星随后认为其技巧、头脑、洞察力与真人相同。可继续绘制多个复制体，本场末另有两名从新出现；未证明无穷数量、无穷魔力或所有伐刀者均可无条件复制。

【本卷战斗进程与卷末状态】
- 她被藏人的双剑与受流技术逼得公开隐藏手段。汤姆森被短剑挡下，战斧被剑茧挡下，死灵大军被〈天衣无缝〉与长剑破解；真正改变局面的是能重现一辉的复制体。
- 藏人最后斩碎一名复制体，但两名新的复制体将其贯穿。裁判中止比赛，宣布莎拉获胜；她全场没有受过一丝擦伤，成为 C 区第三轮对手之一。
- 一辉将要先打白夜，再面对她；第六卷没有开始描写一辉与莎拉的第三轮。

【玩家存档与知识边界】
- 上述赛果是原著基线。若玩家改变对阵、能力展示或攻防，就以存档为准，不能因人物条目强制莎拉获胜或无伤。
- 一辉、史黛菈在访房后知道画家身份；公开观众在第七章看到对应招式后才可知其具现能力。加加美的禄存档案只提供旧 C 级与色彩信息，没有提前收录〈幻想讽画〉。
- 莎拉的强迫与艺术执念不能替玩家设定同意、欲望、感情或裸体模特经历。
