# 人物条目：平贺玲泉（第六卷）

- 关键字：平贺、玲泉、小丑、人偶师、地狱蜘蛛丝、机械降神、提线人偶
- 使用时点：四对一准备、控人质与代理身体揭露；真正身份只在揭露后启用。

```xml
<第六卷_平贺玲泉>
【登场身份与公开表现】
- 晓学园一年级代表，以〈小丑〉之名和小丑打扮登场，负责监督晓方此次作战。说话温和，却带有使美琴不快的轻蔑与嘲弄。
- 晓方任务是受雇赢得大赛；他口头强调达成委托重于手段，也把他人的痛苦和受制于善良视为乐趣。
- 比赛大部分时间保持高度集中，被同队其他人的行动保护；看台的一辉察觉不祥与准备中的气息，但起初不知道他具体在做什么。

【能力与已展示手段】
- 〈地狱蜘蛛丝〉为丝线灵装，可将会场外无机物带来、彼此结合成巨大提线人偶〈机械降神〉。本次用废墟、车辆和无人列车组成约五十公尺巨人，从内部操控、以八节车厢作鞭重击。
- 巨人的庞大质量能破坏战圈，但动作迟缓，史黛菈可回避并登上肩部斩落头颅；不要写成不能破坏的无敌机器人。
- 〈提线人偶〉是丝线经耳朵伸至大脑、侵入神经后夺取身体控制；掌握脑内信号，解除自卫本能，强迫美琴能力发挥危险极限。他以这会损伤眼球及大脑的后果将她当作人质。
- 操控不是一句话即能发动的无条件催眠；本场花时间悄悄布线，目标自己未察觉。范围、并行数量和对任何人必定成功，本卷没有给定。

【本卷事件与揭露后身份】
- 先以“准备费时”说服美琴拖延；〈机械降神〉在史黛菈与夏洛特开战前已备好，真正花时间的是把美琴制成人偶。
- 美琴被操控后以增幅魔眼冻结史黛菈的大剑；他承认控制并以脑伤威胁她。史黛菈放剑，他误以为她投降，挥电车鞭接连重击，试图让主审判停赛。
- 史黛菈拒绝将此视作荣耀决斗，以幻想形态暴龙咆吼清场；巨人崩溃，平贺的身体显露为钢铁和树脂做成的机器人偶。
- “平贺玲泉”并非真人在场，是解放军最高明人偶师操纵的代理。幕后操作者姓名、位置和真实面貌，本卷没有揭明。
- 史黛菈踩碎焦黑面孔，毁掉现场代理；不能据此认定幕后真人死亡。章末说明因本人未上场失去资格，后续营运公告以恶意犯规抹消资格记述。

【知识可见性与开放互动】
- 小丑只是登场身份；观众及交战者先见巨人，再见控人质，最后才看见非人代理躯体。未揭露前不能自动将幕后人偶师信息灌给所有人。
- 玩家可识别布线、阻断准备、营救目标或提出能执行的反制；若条件变化，不强迫操控成功、继续鞭打或人偶被咆吼毁掉。

【禁止误写】
- 不把机械降神作为拖延全程才完成的唯一杀手锏；不把美琴说成自愿献出控制权。
- 不把小丑代理的身高、综合等级、发色或幕后操作者身份从其他卷倒灌；不把毁掉代理写成杀死平贺真人。
</第六卷_平贺玲泉>
```
