# 人物条目：多多良幽衣（第六卷）

- 关键字：多多良、幽衣、不转、不转杀手、完全反射、掠地蜈蚣
- 使用时点：病房对反射相性的讨论、四对一前段交战及其后医疗/弃权处理。

```xml
<第六卷_多多良幽衣>
【身份与可见特征】
- 晓学园一年级代表，〈解放军〉名闻遐迩的杀手，称号〈不转〉／〈不转杀手〉。
- 本卷写明漆黑长发、半永久性黑眼圈和亮出的利牙；不补造身高、骑士等级或额外服饰。
- 固有灵装〈掠地蜈蚣〉为链锯，拉启动绳后以魔力驱动回转刀刃；攻击手法粗糙，仍能以刀刃和蛮力撕裂战圈石板。

【性格与身世】
- 自幼生于代代为解放军效力的杀手家庭，没有把善恶当作普通人那样的行为标准。父亲从她三岁生日起不断暗杀她，历经十余年培养出极佳动态视力与集中力。
- 为被史黛菈以四对一轻视而恼怒；有强烈自尊和杀意，但接受过激动时保持头脑冷静的训练，能观察破风声及右手持剑的不自然来识破佯攻。
- 追击时能反弹攻击，直到歼灭目标都不止步，由此得名〈不转〉。她向作战监督平贺确认公开赛杀人会被当成事故，是两人的态度，不是赛事规则保证。

【能力与战术】
- 〈完全反射〉把冲击或损伤反弹；来袭攻击越强，对手受到反射的威胁越大。在身体外侧布置反弹概念结界，扭转来袭向量。
- 反射依赖她察觉并发动：高速隐蔽攻击理论上可越过反应，但本卷强调其眼力足以捕捉一辉此前模仿爱德怀斯的剑影，不可把普通加速写成稳赢。
- 她与风祭配合：自己引开注意，狮子从死角用〈兽王威吓〉止住目标，再以链锯和兽王行进击出战圈。
- 不提供本卷未给出的射程数字、固定次数上限、常驻自动防御、任意转射第三方或远距离替别人反射能力。

【本卷事件与截至卷末状态】
- 彼方曾以难以完全躲开的〈星尘之剑〉与她交战，无法给她留下擦伤；间章由彼方确认她的反射身份。
- 四对一中首次夹击伤不了史黛菈；她诱其出手，又看穿轻剑斩与左拳连动。两次反射成功，左拳反射粉碎史黛菈手腕。
- 她因计划奏效而出现松懈，没算到史黛菈仍用碎腕把拳头打到底，遭侧腹重击失去意识。反射没有失效，她也没有被杀。
- 医生判定她无法参加原定次轮比赛；后续营运公告收到她与风祭的弃权通知，史黛菈因此省去该区后续比赛。

【知识可见性与开放互动】
- 眼力与父亲训练属叙述揭露，普通观众未必知晓；反射及失利过程通过赛场表现逐渐可知。
- 玩家可通过可靠情报、试探和合作改变她的策略；若战斗与伤势变化，不强迫她仍被碎拳击昏或必定弃权。

【禁止误写】
- 不写史黛菈以剑速骗过她、不写她没反射到左拳，也不将全卷的反射概述扩大成无条件无敌。
- 不混入其他卷人物关系、代号来源或后续生死；此处仅以第六卷已写出的经历为准。
</第六卷_多多良幽衣>
```
