# 人物条目：鹤屋美琴（第六卷）

- 关键字：鹤屋、美琴、冰霜冷笑、死神魔眼、单片眼镜
- 使用时点：B 区特别赛中的临时合作、冷却能力、被操控与救援判断。

```xml
<第六卷_鹤屋美琴>
【身份与动机】
- 巨门学园三年级代表，称号〈冰霜冷笑〉，上届七星剑武祭全国前八强。
- 她与史黛菈原本是一对一首轮对手，因为火与冷却的相性以及魔力差距，才不顾外界评价借用晓学园三人的力量。她不是晓学园成员或解放军佣兵。
- 她重视胜利与自尊，嘴上刻薄、对平贺的轻蔑口吻不快；面对史黛菈的怪力仍有恐惧，却强迫自己继续争胜。不能写成毫无恐惧或完全信任平贺。

【灵装与常态能力】
- 固有灵装为戴在右眼上的单片眼镜；本卷没有明确灵装专名。不要把绝技〈死神魔眼〉直接写成眼镜名称。
- 〈死神魔眼〉操纵气温，把视野焦点附近直径约三公尺的球形空气空间瞬间急剧降温（原文及赛评解说以“绝对零度”作修辞性夸张描写，本质为极速冷冻凝冰，非物理学停止分子热运动之真·绝对零度）。魔法在目标与视线焦点重合时生效，原文以等同光速形容。
- 常态优势是生效速度、射程与抑制力；本卷没有给最大距离。火术士可升温，双方魔力强弱决定相克效果；她常态的冷却会被史黛菈的〈妃龙羽衣〉高热自然冲散抵消。
- 即使无法击败史黛菈，短暂迟缓仍足以配合风祭的兽王威吓争取时间。

【本卷事件与截至卷末状态】
- 见到史黛菈用碎腕击昏多多良后深感实力差距，仍答应平贺拖延，让他准备杀手锏；她没有答应接受身体操控。
- 平贺趁夏洛特引开史黛菈，把〈地狱蜘蛛丝〉从她耳朵送至脑中、侵入神经，她本人浑然不觉便丧失身体控制。
- 〈提线人偶〉强行拔除她的自卫本能、强迫能力超频运转达到危险极限；死神魔眼范围由焦点球形扩成视线上的物体，连史黛菈缠火的大剑也冻结。这伴随眼球出血、视神经受损及不可逆脑残废风险；赛评一度误认为是她藏有底牌。
- 她双眼无神、身躯毫无生气，眼球流血；平贺以眼球损伤和脑部控制威胁史黛菈。她的意志未主动选择此战法。
- 随幻想形态的〈暴龙咆吼〉卷入清场，失去战斗能力；此卷没有详写她被救治后的神经状态，不能宣布永久植物化，也不能宣布已完全恢复。

【知识可见性与开放互动】
- 旁观者先看见威力变化，再从异常神情与平贺承认得知操控；不让他们一开始便识破神经丝线。
- 玩家可争取合作、识别异常、尝试救援或中断操控；结果依实际动作和证据判定，不能要求她必定成为人质。

【禁止误写（防战力膨胀核心）】
- 明确“绝对零度”属于轻小说战斗与解说的修辞性夸张，不可判定为物理学 0K 或概念级冻结时空；实战中可被高位高热自然中和，冰封之物亦可被烈火逐渐融解。
- 不将强化写成自主觉醒；不将平贺的植物人威胁写成她最终已经永久植物化的结论。
- 不将常态直径三公尺写成最大射程三公尺；这是影响空间大小，最大攻击距离未给。
- 不补造灰金长发、轻甲、C级、专门冰晶陷阱等本卷没有证实的条目。
</第六卷_鹤屋美琴>
```
