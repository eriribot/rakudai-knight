# 落第騎士英雄譚 · 模擬戰

黑鐵一輝對史黛菈的單場卡牌訓練戰。以薄頂欄、角色腳下狀態、敵方行動預告和底部手牌呈現日式 RPG 介面；規則與操作使用繁體中文。2026-10-23 依最新回饋將演出簡化為「站立 → 殘影突進 → 揮砍 → 快速歸位」，普通動作設定 290 ms。一輝兩姿態及共用刀刃已整合，本輪 **159 項瀏覽器檢查通過**，畫風與相似度仍待使用者審閱。

## 開啟與操作

在本資料夾執行：

```powershell
node serve.cjs
```

開啟 [本機模擬戰](http://127.0.0.1:4177/)。無套件安裝、無建置、無外部 CDN；亦可直接開啟 [index.html](index.html)。

點擊手牌出牌，`1–6` 對應前六張手牌，空白鍵結束回合，`R` 重開。手機手牌可橫向捲動。右上選單提供招式圖鑑、演示連招、素材對照與動作預覽；「演示連招」會先重開，再完成一個回合，之後可接手。

首次點擊或按鍵後播放通常 BGM，音符按鈕統一切換音樂與音效。一刀修羅播放使用者提供的 GIF 一輪（2.25 秒）並切換專用曲；點「略過動畫」或按 `Esc` 可跳過演出。隨後的修羅文字橫幅保留原本 **1.15 秒**，使用者已允許它暫時遮住人物，不以避開遮擋為由縮短。曲終返回通常 BGM，重開取消進行中的演出，勝敗結算停止音樂，靜音狀態在重開時保留。

## 本場規則

一輝初始 **100 體力 / 10 MP**，史黛菈 **120 體力 / 3000 MP**。每回合恢復 **3 AP**、抽 5 張，MP 不隨回合恢復。固定牌組共 15 張、6 種招式；抽牌堆用盡後重洗棄牌，手牌上限 10 張。

| 招式 | 張數 | AP / MP | 效果 |
| --- | ---: | --- | --- |
| 斬擊 | 4 | 1 / 0 | 12 傷害，普通交鋒解析 +10% |
| 受身 | 3 | 1 / 0 | 14 格擋；本回合下一次敵方攻擊，格擋後傷害最多 4 |
| 看破 | 2 | 0 / 0 | 解析 +20%、抽 1 張；本回合下一張攻擊 +4 傷害 |
| 疾步 | 2 | 1 / 0 | 7 格擋、抽 1 張；沒有受身的傷害上限 |
| 返擊 | 3 | 1 / 0 | 10 傷害，已有格擋時改為 18；普通交鋒解析 +10% |
| 一刀修羅 | 1 | 2 / 10 | 42 傷害、自損 18 體力、本場移除 |

傷害依次消耗魔力護盾、格擋、體力。魔力護盾保留至耗盡，格擋在持有者下一回合開始時清空。受身必須主動出牌，只保護本回合下一次敵方攻擊，不抵消修羅代價；成功格擋或受身使解析增加 15%。

解析跨回合保留，上限 100%。達到 100% 後的下一張攻擊消耗全部解析，穿透魔力護盾；仍受格擋影響，不會自動斬殺，該次穿盾攻擊也不再獲得普通交鋒的 10%。一刀修羅完整支付 MP 與體力代價後才判定勝負，雙方同時歸零算敗北。

敵方依序預告 **22 傷害 / 24 魔力護盾 / 42 傷害**，分別消耗 **60 / 120 / 240 MP**，在回合結束時執行；魔力不足時改為免費的 10 傷害斬擊。**一刀羅剎僅在圖鑑顯示未解鎖**，沒有卡牌定義、效果、解鎖條件或牌堆條目。

## 人物演出與範圍

目前演出只使用站立與揮砍兩個完整姿態：以站姿短暫準備，留下兩道完整人物殘影向前突進，近身時切換揮砍，然後切回站姿快速歸位。正常交戰不播放三步跑動，也不輪播六張姿態。站立、格擋與歸位共用同一畫稿，頭與身體保持完整，不單獨放大頭部；一輝刀刃的共用方式另見下段。

一輝選定 [ikki-anime-two-pose-v3.png](assets/ikki-anime-two-pose-v3.png)，1672 × 941，左為站立、右為揮砍。它以官方臉部／身體設計、實際動畫全身動作與握柄參考組合生成。**尚未找到合格的完整側身待機動畫截圖**，不能稱為直接還原一張 idle 截圖。源圖兩把刀刃仍有長短差；現已讓兩姿態共用左站姿的同一刀刃紋理，人物與刀刃均採 `H / 880`，揮砍只旋轉刀刃 **−37.795966°** 並定位。刀刃軸長保持 **447.934 源像素**，原刀刃由 CSS 遮罩排除，源 PNG 未改。

普通出擊設定為 **40 ms 站立準備、80 ms 殘影突進、90 ms 揮砍、80 ms 歸位，共 290 ms**。必殺只將準備延長為 90 ms，場上動作合計 **340 ms**，不含 GIF。近身後保留間距 `min(H × 0.7, 雙方原間距 × 0.72)`；刀光與火花在揮砍時出現，狀態欄留在原站位。修羅原有 **1.15 秒**文字橫幅保留。

本輪實播已核對一次命中、重開取消殘影與未完成動作、減少動態時正常結算。[動作預覽](motion.html)提供雙方共 4 個姿態控制，揮砍計數為 `02 / 02`；[素材對照](references.html)展示目前姿態、真實動畫來源，早期參考收進折疊存檔，390 px 檢查無水平溢出。現行合同與交付狀態見 [兩姿態演出記錄](docs/simple-motion-20261023.md)。

本場由 [battle.js](battle.js) 的純本地引擎結算，`hp` 在介面代表幻想形態訓練戰的體力。本次 HP、MP、AP 與傷害是獨立試玩標定，沒有接入酒館、MVU、世界書或存檔，也沒有修改 schema。[現行 MVU 更新規則](../世界书规则/MVU/变量更新规则.txt) 明確不設統一 HP/MP/AP/SP，不能把這些本地數值反寫成原作或現行 MVU 規則。舊討論稿中的 S 關係綁定、覺醒前置等沒有採用，一刀修羅不等於魔人覺醒。

完整規則、素材邊界與驗證記錄見 [本輪實作說明](docs/trpg-battle-20261022.md)。[10 月 22 日視覺提案](docs/battle-ui-redesign-20261022.md) 保留當時設計過程，其中舊數值與未實作狀態不代表目前版本。
