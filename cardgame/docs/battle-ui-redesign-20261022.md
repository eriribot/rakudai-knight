## 已确认的问题与证据

- 现有战场左上大标题、口号、左右人物介绍板占据交锋空间。意图位于屏幕角落，与敌人分离。
- index.html 加载 actors.css、stella-frames.css、ikki-unified.css。当前 DOM 没有独立头部图层，ikki-unified.css 也隐藏历史 actor-head。
- actors.js 的攻击/受击主体使用平移；scale 主要作用于光效。未发现攻击单独放大人物头部。
- 一辉待机图片按 actor-height / 1536 显示；动作图按 actor-height / 480 显示。源图中的头身比例存在差异，切帧后头相对身体偏大。只缩小整个动作图会同时缩短身体。
- 格挡与看破同样切到 guard，所以比例变化可能发生在多种行动中。
- 脚底锚点已有专门计算；当前证据不支持将主要原因归咎于脚底锚点。
- 本次真实浏览器打开 motion.html，通过现有“第 5 格，斩击”按钮比较待机与斩击；证据为 [待机](../../output/playwright/cardgame/design-review-idle-20261022.png)、[斩击](../../output/playwright/cardgame/design-review-slash-20261022.png)。这里只验证现存问题，没有验证修复效果。

## 布局

| 区域 | 提案 |
| --- | --- |
| 顶栏 | 约 48–56px；左侧作品名、破軍學園／模擬戰；中央回合与行动方；右侧音效、帮助、菜单 |
| 战场 | 主要画面留给双方全身角色；脚底同一地面，中央有交锋余量；删除大标题、口号和 VS 装饰 |
| 人物 | 约在画面宽度的 28% / 72% 站位；以地面节点定位。角色约占总画面高度三分之一，按可用高度响应 |
| 敌方意图 | 贴近史黛菈头顶或头侧；图标 + 数值优先，招式名次之；不能遮住头发或刀剑 |
| HP / 格挡 | 紧凑姓名、细血条与盾形数值放在脚下；跟随站位布局，攻击时仍固定在原位以便阅读 |
| 手牌 | 底部约 26–30% 的渐暗区域；5 张微扇形排列，费用、名称、规则层级明确；只给当前悬停／键盘聚焦的牌高亮 |
| AP / 结束回合 | 分列手牌两侧；AP 高可读，结束回合为唯一主要实色按钮；抽弃牌堆作为次操作 |
| 工具入口 | 素材对照、动作预览、支援会话、演示连招收进菜单，保持可访问 |

色彩建议：深墨蓝背景、米白文字；我方青蓝、敌方朱红；少量暖金只标主要操作。细边与字级承担信息层级，减少常驻光晕、英文小字和装饰符号。

手机 390px：顶栏合并为短标题与菜单；保留战场和紧凑血条，意图紧贴敌方；手牌横向滚动，AP 与结束回合固定在同一可见操作行。点击牌前可查看完整效果，键盘和触屏均有明确选中态；不把桌面布局整体缩小。

## 人物行动：推荐落地方案

首版推荐全程使用同一张完整人物母版，将头、身体、衣服和武器视为一个不可拆分的整体。短距离进身、刀光、命中停顿、受击后撤和返回原位提供行动反馈；普通动作不改变人物缩放。这个方案的优点是比例稳定，局限是没有真正的逐帧挥刀，应如实展示。

建议普通攻击节奏：短促预备 → 进身 → 命中时一次结算 → 刀光收束 → 返回。进身幅度约为战场宽度的 4–7%，上限约 96px，实际观感需实机调整；避免长距离滑行。地面阴影随主体平移，血条留在原站位；全屏镜头保持稳定。

保留一刀修罗 GIF、跳过、BGM 切换和静音。必杀的强调来自独立演出与光效，不通过把场上人物放大实现。继续支持减少动态效果、重开取消动画与 onImpact 只结算一次。

过渡备选：待机也使用动作表 guard，让全部姿势使用同一倍率。它能减少跨两套图的跳变，但仍保留动作表偏大的头身比，不作为最终素材标准。

长期动作素材：从同一母版绘制待机、前踏、蓄势、挥砍、受击和收势；锁定头高、肩宽和躯干长度，记录脚底与根节点。蹲伏时允许整体包围框变矮，不能按每帧高度重新撑满同一个盒子。必须先做等倍率并排与循环慢放审查，再替换战场素材。

## 实施边界与顺序（提案）

1. 在现有 actors.js、actors.css 和角色样式中落实一致人物比例，保留原有结算与取消契约；不靠继续追加覆盖样式掩盖旧问题。
2. 修改 index.html、styles.css、app.js 的界面结构和文案；尽量保留现有 DOM ID、按钮事件、可访问名称与键盘操作。
3. 对照最新状态显示意图、AP、手牌、HP、格挡与看破效果；battle.js 继续作为唯一战斗规则源。
4. 同步 motion.html 的动作说明，避免预览页仍宣称已具有未实现的真实挥刀；相关标题、帮助和结算统一用词。
5. 补充桌面、窄屏及动作验证结果，再由用户检视观感。

现有 HP/AP、伤害、牌堆、敌意图、胜负、音乐和必杀规则不在改版范围。此次不新增战斗机制、依赖框架、在线服务或酒馆接入。

## 图稿与实现的差别

- 概念图中的“下回合：攻擊”在实现时必须改为“回合結束時攻擊”，准确表达当前敌行动时机。
- “看破”的效果说明必须保留“本回合”限制，不能仅凭图中的短句变更规则。
- 概念图对多张卡使用了蓝色外发光；实现时仅悬停、聚焦或选中牌高亮。
- 概念图的 AP 球与按钮装饰可以简化，优先实现可读性与操作反馈。
- 卡面继续使用项目已有可追溯素材；不把概念图里的新插画直接当成生产资源。
