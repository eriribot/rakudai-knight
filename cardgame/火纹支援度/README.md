# 羁绊之间 · 火纹式支援会话概念预览

史黛拉 × 黑铁一辉的 C 级支援《再陪我练十分钟》。作为卡牌战斗之后的关系系统展示：**选择支援对象 → 观看会话 → C 级达成 → 列表回看**。18 句原创同人对白，约 2 分钟。

## 打开

直接打开 `index.html`，无需安装依赖或构建。也可以在 `cardgame` 目录运行 `node serve.cjs`，访问：

<http://127.0.0.1:4177/火纹支援度/index.html>

原卡牌战斗页顶部也已增加「支援会话」入口。此页面相对引用既有的 `../assets/arena-duel.png`，移动时请保留整个 `cardgame` 目录。

## 操作

- 点「观看 C 级支援」进入。点对白框，第一次补全文字，再点推进；`Enter` / `Space` 也可推进。
- 「自动」按台词长度等待后推进；「回顾」查看本次已读台词，并暂停自动播放。
- `Esc` 关闭回顾；在剧情中则返回列表。提前退出不结算。
- 读完最后一句并继续后解锁 C；刷新后保留状态。回看不重复写入完成记录。
- 「重置演示」仅清除 `rakudai-support-demo-v1` 这一个本地存储键。存储被禁用时，仍可完整游玩本次事件。
- 遵循系统「减少动态效果」设置，停止逐字、呼吸、眨眼和口型。

## 美术与分层

视觉采用纸张底色、深蓝菜单、金色等级徽章和双人立绘。借鉴《觉醒》的支援会话体验，并非界面资源移植。菜单中的 B、A、S 以及其他角色仅表示后续方向，本次不开放。

动画官网人设图作为身份、服装和画风参考；运行立绘通过内置 `image_gen` 重新制作。它们是 **AI 生成衍生素材**，不冒充官方透明原稿。

| 文件 | 用途 | 规格 |
| --- | --- | --- |
| `assets/ikki.png` | 一辉中性立绘 | 1024×1536，PNG alpha |
| `assets/stella.png` | 史黛拉身体与中性脸 | 1024×1536，PNG alpha |
| `assets/stella-expression.png` | 同画布的闭眼、张口编辑稿 | 1024×1536，PNG alpha |
| `../assets/arena-duel.png` | 既有项目的生成训练场背景 | 仅做 CSS 取景 |

完整提示词及内置工具模式记录在 `assets/ikki-generation.json` 和 `assets/stella-generation.json`。官方资料来源及既有本地图的证据边界见 `assets/sources.json`。

参考用户提供的《菈菈分层动态立绘制作与接入指南》采用固定画布、局部窗口、整体缩放的思路。本次新制素材有原生 alpha，因此不需要另做 mask，也不套用菈菈的旧 Unity 图集尺寸或脸部坐标。

`portrait.js` 是本演示的坐标权威：眼窗 `435,205,153,60`，嘴窗 `496,277,50,31`，都在 1024×1536 主画布内。中性状态读取 body，闭眼和说话状态从同画布编辑稿采样；手机端只缩放整个人物。史黛拉有两状态眨眼和说话口型，一辉使用静态脸、轻微呼吸与发言强调。这是局部贴图动画，无音素分析，也不是 Live2D。

双人取景使用独立于脸部图层的画布归一化：一辉源图是膝上，史黛拉源图接近全身，因此史黛拉画布显示宽度始终为一辉的 1.4 倍，才能让脸宽、头高及肩部处在接近的尺度。站位按主发顶锚点对齐（一辉源坐标 y=86、史黛拉 y=94，不含蝴蝶结），不是按图片底部对齐。桌面和手机都保持这个相对比例；只等比缩放完整 rig，不拉伸躯干或单独移动五官。

## 实现范围

本演示的训练前置默认已满足，C 级在浏览器内独立保存。没有接入卡牌战斗结算、MVU、酒馆聊天楼层或正式战斗加成；也没有 BGM、配音及 B／A／S 事件。它用于展示点击到支援预览的完整感受。

`story.js` 保存原创对白；`support.js` 管理打字、日志、自动播放与结算；`support.css` 管理纸张菜单、演出和响应式布局。
