## 這次重畫要保住的辨識點

- 下半臉短、下巴小，雙頰保留寬度；不要削成修長的成年男性尖臉。
- 待機時眼神溫和，眼睛下緣保留弧度；不要把所有姿態都畫成細長銳眼。
- 黑／深棕色不對稱碎髮與斜瀏海，沿用官方設計圖的頭部輪廓。
- 制服以動畫版長袖、黑色高領、灰色格紋翻領和白色外套為準。
- 戰鬥時可以改變眉眼和嘴形，但同一張臉的基本比例要保持。
