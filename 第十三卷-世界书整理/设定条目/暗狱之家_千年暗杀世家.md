# 设定条目：〈暗狱之家〉（Abgrund / 千年暗杀世家）

- **条目 ID**：`setting-abgrund`
- **条目名称**：暗狱之家（Abgrund / Up Grund）
- **所属阵营**：地下社会最深处 / 〈解放军〉契约雇佣暗杀势力
- **性质定位**：传承千年的世袭顶级暗杀武装集团
- **核心人物**：家主（已故）、初代首席一号〈恶之华〉艾茵·阿伯伦特（叛变灭门者）、四号菲亚 / 多多良幽衣（唯一幸存者兼家主之女）
- **登场出处**：第十一卷第六/九章、第十二卷第十三/十四章、第十三卷第十七章、第十五卷终章

## 世界书词条正文（SillyTavern World Info）

```xml
<暗狱之家>
【组织定性与千年底蕴】
〈暗狱之家（Abgrund / 原著音译 Up Grund，德语意为“深渊”）〉是盘踞于地下社会最深处、传承超过千年的世袭暗杀集团与隐秘武装势力。
- 渊源与历史：历史远比现代跨国恐怖组织〈解放军（Rebellion）〉更早出现。传说历史上无数成为历史转折点的刺杀大案背后均有其插手，但组织据点与首脑行踪极其隐秘；
- 阵营契约：近代与〈解放军〉缔结长期契约，作为其麾下隐于至暗之处的王牌杀手部队执行地下清缴；
- 潜入神话与三大禁地：号称世界顶级潜入暗杀专家，其千年记录中全球仅有三处设施被认定为“绝对无法潜入”，其中之一便是中国神龙寺关押重罪犯的修罗地狱“极苦楼”。

【极端等级与残酷品管激励体系】
组织以冰冷机械的“品质管理”将幼女锻造成暗杀兵器，并在内部推行残酷的胜者特权与物质激励：
1. 抹杀个体身份（无名兵器）：在世界各地收容被遗弃的幼女（乃至家主亲生骨肉如多多良幽衣），统称〈姊妹（Sisters）〉。剥夺姓名与个体人格，仅以德语编号相称（一号艾茵 Ein、四号多多良菲亚 Vier 等），要求能按任务随时化身为任何国籍身份的任何人；
2. 绝对饮食管控：严禁普通餐点，日常餐餐皆为精密调配的合成营养剂；每日抽血验尿、每周全身体检，严禁一丝多余体脂与资源浪费；
3. 实弹厮杀与两极医疗待遇（再生槽特权）：
   - 全员在训练中严禁使用〈幻想形态〉，必须以真刀真枪、实弹进行血腥对打，负伤已是家常便饭；
   - 【胜者特权·再生囊/再生槽（Capsule）】：唯有在严苛训练中拔得头筹（第一名）或工作极优异的极少数天才（如一号艾茵），才有资格立刻进入〈再生囊/再生槽（Capsule）〉接受高阶细胞修复，迅速愈合创伤且免受痛苦；
   - 【败者炼狱】：成绩普通或落后者，仅能获得避免死亡的粗暴消毒、止血与缝合，教官严禁提供任何止痛剂，任由其蜷缩在走廊忍受剧痛（“不想受伤忍痛？那就给我变强”）；
4. 唯一的精神支柱与生存动力——【奖励巧克力】：
   - 在缺乏正常人际关怀与美食的味觉荒漠中，唯有“顺利完成暗杀工作”或“在训练中夺得第一名”的杀手，方能获赐一颗又小又便宜的普通巧克力作为「奖励」；
   - 这颗在舌尖融化的巧克力是女孩们在无间地狱中所能品尝到的唯一一样“幸福”，亦是支撑她们在残酷淘汰中拼死活下去的生命支柱（艾茵曾以初吻将奖励巧克力渡入腹部中枪哭泣的菲亚口中，让其初次感受幸福并萌生生存执念；多多良终身恪守“巧克力是劳动报酬，绝不接受施舍与免费巧克力”的杀手哲学）；
5. 极限特训与耐拷问：在零下雪山无衣无食独自野外求生一个月；经受极端酷刑确保受俘至死绝不泄露雇主情报；
6. 终极结业试炼·〈遴选（Selection）〉：将受训成熟的〈姊妹〉关入密闭空间彼此残杀，唯有踩着同门尸体胜出的最终幸存者方可正式出师。

【职业信条与致命底牌】
- 核心铁则：“杀手是世界上最讲信用的行业”。暗狱之家的无上信条是誓死履行契约、绝不可伤害客户。多多良之所以舍命追杀艾茵，并非出于父母亲情被灭之仇，而是因为艾茵背信屠杀客户与同门，在暗狱之家千年的“信誉”上抹了黑，必须由门内杀手用血洗雪；
- 专属绝杀禁药：每位出师杀手皆配发一片封存于臼齿内侧的同归于尽禁忌兴奋剂〈天使碎尘（Angel dust）〉；
- 隐秘养护基地：在大本营之外秘密建有高度自动化的地下医疗整备与修养基地，供残存杀手战后自行疗伤与复健。

【组织的灭亡与传承断绝】
- 绝顶天才反噬：初代首席一号〈恶之华〉艾茵·阿伯伦特在精神彻底异化后暴走叛乱，亲手屠灭父母、全部同门姊妹并袭击客户解放军，暗狱之家本土近乎灭绝；
- 奎多兰终局：第十三卷路榭尔王城决战，仅存的四号菲亚（多多良幽衣）以重残之躯反杀艾茵，完成家门清算。暗狱之家在建制与血脉意义上均告终结，仅剩残疾退隐的多多良幽衣独自背负其最后名誉。
</暗狱之家>
```

## 原著 GBK 考据证据链

- `第十三卷 第十七章`：**再生囊与残酷淘汰机制**：
  > “她们连进行最基础的战斗训练都不能使用〈幻想型态〉，必须时时刻刻手握真刀、真枪，和其他〈姊妹〉或大人互相厮杀。训练时受重伤已是家常便饭。假如她们在训练中取得优秀成绩，还能马上接受〈再生囊（Capsule）〉治疗。但大部分〈姊妹〉可没有这种待遇。她们顶多能接受最基本的治疗，消毒、止血、缝合伤口避免死亡，之后就放置不管，直到下一次训练为止。教官甚至连止痛剂都不给。简直像是告诉她们：‘不想受伤忍痛？那就给我变强。’”
- `第十三卷 第十七章`：**第一名奖励巧克力与艾茵初吻之糖**：
  > “艾茵扬起唇角……『初吻的滋味如何？甜滋滋的对吧？』……方才，某样物体沿著交叠的双唇流入菲亚口中。这股甘甜，比她唯一尝过的蛋白质甜味还要甜上几十倍……艾茵从口袋取出皱巴巴的包装纸，告诉她：『这是巧克力。我们成功做好工作、训练拿了第一名，就可以得到巧克力。不过菲亚这个万年吊车尾根本不知道吧。』……她想以自己体会过的唯一一样‘幸福’为目标，努力取得奖赏用的巧克力。”
- `第十二卷 第十四章`：**巧克力的工作报酬哲学与千年历史**：
  > 多多良向史黛菈解释为何拒绝免费巧克力：“『那时候的每一天都快把人搞成疯子。唯一的乐趣，就是当我们顺利完成工作之后，可以得到一颗巧克力当「奖励」……那只是一颗又小又便宜的巧克力。但是对当时的她们来说，这颗巧克力是生存的动力。所以对我来说，巧克力比较类似工作报酬，是劳动的代价。别人免费送给我，我也不会开心啦。』”
- `第十二卷 第十三章`：**世界三大禁地之一**：
  > “〈暗狱之家〉在这世界上无法成功入侵的地方只有三个，‘极苦楼’就是其中之一。”
- `第十五卷 终章`：**秘密养护基地**：
  > 多多良搭机离开法米利昂：“她输入座标，准备前往〈暗狱之家〉的养护设施。”
