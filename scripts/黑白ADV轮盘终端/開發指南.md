# 落第騎士·黑白ADV輪盤終端 - 開發指南

## 📁 項目結構

\\\
scripts/黑白ADV轮盘终端/
├── main.js              # 主邏輯模塊
│   ├── hostWindow()     # 宿主窗口檢測
│   ├── viewport()       # 視口管理
│   ├── buildDom()       # DOM 構建
│   └── show/hide()      # 顯示/隱藏控制
│
├── wheel.js             # 輪盤組件
│   ├── buildWheel()     # 輪盤 SVG 構建
│   ├── toggleWheel()    # 展開/收起動畫
│   └── openPhoneApp()   # 應用導航
│
├── styles.css           # 樣式表
│   ├── #rk-orb          # 懸浮球樣式
│   ├── #rk-shell        # 終端窗口樣式
│   └── #rk-wheel        # 輪盤樣式
│
├── terminal-app.html    # 終端應用頁面
│   ├── 8 個應用入口
│   └── MVU 數據綁定
│
├── config.js            # 配置管理
│   ├── ANIMATION_CONFIG # 動畫參數
│   └── TEST_DATA        # 測試數據
│
└── build.js             # 打包腳本
\\\

## 🔧 開發流程

### 1. **安裝依賴**
\\\ash
cd scripts/黑白ADV轮盘终端
npm install
\\\

### 2. **修改源碼**
- **調整動畫**: 編輯 \config.js\ 中的 \ANIMATION_CONFIG\
- **修改樣式**: 編輯 \styles.css\
- **添加功能**: 編輯 \main.js\ 或 \wheel.js\
- **更新 UI**: 編輯 \	erminal-app.html\

### 3. **構建腳本**
\\\ash
npm run build
\\\
生成的文件：\E:/web/落第/酒馆助手脚本-小手机-黑白ADV轮盘版-v1.2.1.json\

### 4. **測試**
1. 在 SillyTavern 中刪除舊版本腳本
2. 導入新生成的 JSON 文件
3. 啟用腳本並刷新頁面
4. 測試所有功能

### 5. **版本發布**
1. 更新 \uild.js\ 中的 \VERSION\ 常量
2. 更新 \CHANGELOG.md\
3. 運行 \
pm run build\
4. 提交到 Git

## 📝 常見修改場景

### 場景 1: 調整輪盤展開速度
\\\javascript
// config.js
export const ANIMATION_CONFIG = {
  wheelOpen: {
    duration: '0.3s',      // 改為 0.3 秒
    easing: 'ease-out',
    scale: { from: 0.8, to: 1 }  // 更明顯的縮放
  }
};
\\\

### 場景 2: 修改懸浮球位置
\\\javascript
// main.js - 找到 clampOrb() 函數
function clampOrb(x, y) {
  const vp = viewport();
  return {
    x: Math.min(Math.max(x, vp.x + 20), vp.x + vp.w - ORB_W - 20),  // 增加邊距
    y: Math.min(Math.max(y, vp.y + 20), vp.y + vp.h - ORB_H - 20)
  };
}
\\\

\\\javascript
