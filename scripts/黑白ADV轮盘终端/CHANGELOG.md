# 更新日誌

## v1.3.28 (2026-10-11)

破军 LIME 改为聊天列表、搜索、联系人与左右气泡界面；沿用人物盾形头像，提供 MVU 时间分隔、可折叠联络资料和固定底部输入栏，配色跟随终端黑白主题。快捷动作只准备草稿，Enter 换行，Ctrl／⌘ + Enter 发送。

发送改为酒馆助手辅助生成：复用当前预设与本局上下文，明确读取世界书人物性格及当前关系、好感、支援资料；缺少人物词条时停止发送。通讯按发信时所属楼层的 MVU 时间记录在 `data.rk_lime`，与 `stat_data` 分开，带楼层／swipe 所有者以拒绝继承复制的旧附件；一次通讯不增加酒馆楼层、不直接改 MVU 或好感。当前分支附件在下一次正常主生成中按长度边界注入，主剧情也可通过显式 `<LIME>` 产生主动来信。加入来源核对、生成与双击锁，保留主输入框和失败草稿。接入依据为 Tavern Helper 4.8.19 公开契约，运行时检查能力。

正文来信保存 `narrative` 时间快照，附属交换保存 `narrativeCount` 位置，保留同页续写前的旧时间与来信顺序；新流式来信等待完成。见证删楼／删 swipe 后只重绑确认保留的原件所有者，隔离已知继承副本，无来源证据不猜测。正式主生成前，显式读取最近通讯且已通联的最多 3 人世界书原文、当前关系及主角模式；其他人物仍走原世界书触发。

本次只更换同名 [小手机 v1.3.28](../../世界书规则/MVU/落第骑士-小手机-v1.3.28.json)，版本号与配套沿用。保存确认目前只代表进入宿主保存队列，磁盘落盘及真实 SillyTavern 全链路尚未验收；`sample=lime` 是虚构预览，发送保留原有两条剧情楼层，不生成 NPC 回答。完整契约见 [LIME 回合与上下文](LIME回合与上下文.md)。

## v1.2.1 (2026-09-07)

### ✨ 新特性
- 🎨 **模塊化開發結構**：將單一 JSON 拆分為可維護的模塊
- 📦 **自動打包工具**：使用 
pm run build 一鍵生成發布版本
- ⚙️ **配置文件分離**：動畫、測試數據等配置集中管理

### 🐛 修復問題
1. ✅ **輪盤展開動畫**：增強從 scale(0.92) 到 scale(1) 的漸入效果
2. ✅ **終端打開時隱藏輪盤球**：添加 CSS 規則自動隱藏懸浮球
3. ✅ **移除硬編碼測試數據**：將所有測試數據移到配置文件
