# 更新日誌

## v1.2.1 (2026-09-07)

### ✨ 新特性
- 🎨 **模塊化開發結構**：將單一 JSON 拆分為可維護的模塊
- 📦 **自動打包工具**：使用 
pm run build 一鍵生成發布版本
- ⚙️ **配置文件分離**：動畫、測試數據等配置集中管理

### 🐛 修復問題
1. ✅ **輪盤展開動畫**：增強從 scale(0.92) 到 scale(1) 的漸入效果
2. ✅ **終端打開時隱藏輪盤球**：添加 CSS 規則自動隱藏懸浮球
3. ✅ **移除硬編碼測試數據**：將所有測試數據移到配置文件

### 📁 項目結構
\\\
scripts/黑白ADV轮盘终端/
├── main.js              # 主邏輯（狀態管理、DOM 構建）
├── wheel.js             # 輪盤組件（8 個應用入口）
├── styles.css           # 樣式表（黑白像素風格）
├── terminal-app.html    # 終端應用頁面（iframe 內容）
├── config.js            # 配置管理（動畫、測試數據）
├── build.js             # 打包腳本
├── package.json         # 項目配置
└── README.md            # 開發文檔
\\\

### 🚀 使用方式
\\\ash
# 開發
npm install
npm run build

# 發布
