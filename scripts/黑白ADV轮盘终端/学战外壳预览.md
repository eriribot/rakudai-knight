# 学战 × 黑白 ADV：共用终端外壳预览

2026-11-03。修正此前独立 dashboard 与既有终端脱节的问题。

## 预览

在工作区根目录运行：

```powershell
node scripts/黑白ADV轮盘终端/preview-asterisk-shell.mjs
```

通过工作区的本地 HTTP 服务打开 `scripts/黑白ADV轮盘终端/dist/asterisk-shell-preview.html`。

加载的是 `buildTerminal({ asteriskPreview: true })` 编译的真实宿主脚本，继续使用 `main.js → wheel.js → openPhoneApp → mountPhone`。浮动入口、拖动、视窗、八项导航和收起行为由既有外壳负责；学战内页实现同一 `RKBoot / openApp / goHome` 接口。原 `scripts/学战六花终端` 保留为视觉草稿，现以此集成预览为评审入口。

## 已实现

- 落第：保留黑白入口、扇形轮盘和原应用页。
- 学战：六边浮动入口、八节点展开轮盘、青色科技视窗，以及同窗内的学生档案、通讯、动态、论坛、赛事、画廊、校历、设置。
- 档案展示学园、校内序列、星辰力、能力机制及武装；不套用伐刀者评级。
- 五校切换用于独立预览样本与内页配色。没有正式选校写入。
- 人物原图不重绘；画廊包含六边头像与长短台词排版示例。通讯只展示样本中已有联系方式的人物，不由图鉴自动建立关系。
- 动态、论坛、赛事、校历保留明确空态；未实现这些业务的写入或生成。

## 路由与交付边界

`asterisk-presentation.js` 暂以讨论中的 `系统.作品 === 'asterisk'` 选择皮肤，还必须具备构建期 `ASTERISK_PREVIEW=true`。默认 `buildTerminal()` 保持此开关为 false，不内嵌学战内页，也不因存档中的未知字段擅自启用。**这不是正式 MVU 契约已经完成的声明。**

预览使用独立内存快照与存储；bridge 仅提供读取、订阅和视窗操作。没有模型、校正、赛事、名册、LIME 发送或 MVU 写入能力。外层 CSP 禁止网络连接；生成和写入接口使用计数后抛错的桩。正式事件接线及 MVU 兼容安装不在预览中启动。

本次没有运行 `build.js`，没有更新 `世界书规则/MVU` 的发布 JSON，也没有导入酒馆。正式接入仍需一起讨论 schema、初始化、主提示词、副校正、剧情门禁和历史消息气泡。
