# 正则性能修复 v0.6.1

日期：2026-11-13。交付模式：`component`，源码与三条可导入角色局部正则。未打整卡，未改玩家 PNG、世界书或聊天存档，未启动临时服务、浏览器或新建临时测试目录。

## 原因

TT 截图明确显示两条规则执行超过 1500 ms 后被暂停。慢点在气泡上下文检查：每个候选姓名／冒号位置都可能重复扫描此前全部 HTML、围栏和保护标签。旧卡 0.04 的 02 与 0.06 完全相同；0.06 的 01 主要增加学战姓名，不能把“只在新卡遇到”直接等同于“新卡才引入慢正则”。详见同目录 `20261113-TT正则超时排查.md`。

## 源码改动

- `build.mjs`：前缀完全没有 `<`、反引号和波浪号时走普通正文快速分支；结构化内容继续走原 `buildContextGuard({opaqueDrivers:true})`。
- 对明确识别的本卡开局文档，在复杂检查前拒绝对白转换。识别条件为文档起点、可选 Markdown HTML 围栏、doctype，以及前部 1024 字符范围内的本卡完整 title；不按所有 HTML 文档一概排除。超过该范围或其他模板仍按原保护规则处理。
- 三条名称、CSS 标记、构建回执版本同步为 v0.6.1。稳定 ID、01 的宏转义、角色局部 AI 显示范围、深度、编辑重绘以及原 HTML 替换结构保持。
- `context-guard.mjs` 本身不改，保留其他调用方行为；03 也共用检查，所以随 01、02 一起发布。
- 现有 `check.mjs` 增加本卡页面原样保留和普通 HTML 正文不被误排除两项；现有 `check-performance.mjs` 增加 30 万字普通正文和仓库真实开局文本。没有搭建新的测试环境。
