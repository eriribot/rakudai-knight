# 《落第骑士英雄谭》第十五卷：出场人物全量索引与阵营图谱

## 1. 阵营分布总览

第十五卷登场人物横跨五大主要势力：
1. **法米利昂王国与国际魔法骑士联盟支援方**：黑铁一辉、史黛菈·法米利昂、黑铁珠雫、西京宁音、希留斯·法米利昂、雅丝忒莉亚·法米利昂、露娜爱丝·法米利昂、席格娜、丹尼尔·丹达利昂、堤米特、米利雅莉亚、雷薇·阿斯卡里德（口信提及）、布马（随军记者）；
2. **奎德兰王国与〈第一王子〉阵营**：欧尔＝高尔（本名欧尔雷斯·格尔）、艾莉丝·阿斯卡里德（〈黑骑士〉）、约翰·克里斯托夫·冯·科尔布兰德（奎德兰第二王子，正统复辟方）；
3. **〈暗狱之家（Abgrund）〉（第三方协战者）**：多良由衣（真名：菲亚 / Fia）；
4. **〈解放军〉残党与日本政商首脑**：风祭晄三、风祭凛奈、夏洛特·科黛、莎拉·布拉德莉莉、华伦斯坦（欧尔＝高尔回忆出场）、月影獏牙（日本首相）；
5. **〈大国同盟（Union）〉/ 美利坚合众国〈PSYON〉部队**：亚伯拉罕·卡特（〈超人 / The hero〉）。
