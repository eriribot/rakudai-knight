# 人物档案：诸星雄大（〈浪速之星〉）

## 1. 基础档案

| 字段 | 设定数据 |
|---|---|
| **本名** | 诸星雄大（Moroboshi Yudai） |
| **称号** | 〈浪速之星〉、前任〈七星剑王〉 |
| **所属院校** | 武曲学园三年级（近畿地区代表名校） |
| **灵装** | 〈虎王〉（兼具刚猛破坏力与精密操控性的长枪） |
| **伐刀绝技与特质** | 〈三连星〉（高速三连刺）<br>〈帚星〉（通过手肘精妙变轨制造枪身弯曲错觉的突刺）<br>〈虎噬〉（咬碎敌方灵装魔力结构并造成精神冲击）<br>〈盲点刺击〉（锁定对手眼球视神经盘生理死角、随机变换初速与加速度的不可视刺击）<br>〈无双一烈〉（缩短枪距集中一点的沉重警告突刺）<br>**〈杀手本能（Killer Instinct）〉**（超越数据与逻辑、在绝境中莫名看穿对手死穴的天生直觉） |
| **初登场卷次** | 第六卷（七星剑武祭） / 第十六卷第二章深度展现其〈杀手本能〉与赴华备战 |

## 2. 战力机制与武道境界

1. **令〈天眼〉畏惧的怪物——〈杀手本能〉**：
   在第二章武曲学园新闻社专访中，上届七星剑武祭亚军〈天眼〉城之崎白夜（小白）坦言自己对二次交手的敌人胜率高达九成以上，唯独对同窗好友诸星雄大挑战千百次未尝一胜。原因在于诸星虽招式正统朴实，却天生具备超越一切数据预测、在绝境中精准锁定对手致命死穴的**〈杀手本能（Killer Instinct）〉**，令白夜感到比黑铁一辉更毛骨悚然。
2. **视神经死角的〈盲点刺击〉**：
   在联盟日本分部擂台与〈剑士杀手〉仓敷藏人的交锋中，面对藏人天生克制点攻击的〈神速反射〉以及〈大蛇丸〉被〈虎噬〉咬断后瞬间再生伸长十余米的不利局面，诸星故意在挨打中观察试探，锁定藏人眼球视神经盘的生理视觉死角，突入中距离发动完全不可视且每次随机变换初速与加速度的**〈盲点刺击〉**，一举废掉藏人的〈神速反射〉并将其逼至绝境。
3. **备战中国〈斗神杯〉与败北瞬间的警告之枪〈无双一烈〉**：
   妹妹小梅的失语症好转后，诸星准备在明年旧历新年后远赴中国参加世界级职业赛事**〈斗神杯〉**（预赛为全中国广阔土地上的残酷生存淘汰赛）。当藏人用牙齿咬住枪尖、贯彻绫辻海斗点拨化〈天衣无缝〉为「火山碎屑流」并以双短刀〈八岐大蛇〉突破三米防线时，诸星坦然承认自己在体能、异能与野性直觉上败给这位“暴力天才”；但因在藏人纯粹的暴力中嗅到与昔日地铁事故魔人同源的危险气息，诸星在倒地前的交错瞬间缩短枪距，在藏人胸口刺出扎实沉重的**〈无双一烈〉**作为警告（告诫藏人若沦为魔物下次定不饶他），令赢家藏人脸色惨绿、生平首次感到来自灵魂深处的恐惧。
