# 人物档案：诸星雄大（〈浪速之星〉）

## 1. 基础档案

| 字段 | 设定数据 |
|---|---|
| **本名** | 诸星雄大（Moroboshi Yudai） |
| **称号** | 〈浪速之星〉、前〈七星剑王〉 |
| **所属院校** | 武曲学园三年级（关西关东巅峰名校） |
| **灵装** | 〈虎王〉（一柄兼具刚猛与韧性的金黄大枪） |
| **伐刀绝技** | 〈帚星〉（能够弯曲枪轨的超长距离弧度突刺）<br>〈虎噬〉（刺击命中后咬碎敌方灵装魔力结构）<br>〈盲点刺击〉（利用对手视网膜盲点施展的不可见枪法） |
| **初登场卷次** | 第六卷（七星剑武祭） / 第十六卷深度展现其枪斗术革新与国际赛备战 |

---

## 2. 战力机制与武道境界

1. **关西枪术至尊**：
   诸星雄大在关西被称为〈浪速之星〉，是上一届七星剑武祭的全国总冠军。其枪术不仅势大力沉，更极度讲求精密战术算计与心理博弈。
2. **三米死线与战术压制**：
   其武器〈虎王〉攻击范围达三米。在第二章与仓敷藏人的地下较量中，诸星通过〈盲点刺击〉完全剥夺了常人的目测反应，再以能中途变轨的〈帚星〉在中距离构筑起坚不可摧的立体封锁线。
3. **备战〈斗神杯〉（中国世界级大赛）**：
   三年级七星剑武祭结束后，诸星雄大并未停下脚步，而是获得了代表日本赴中国参加世界级职业顶尖赛事**〈斗神杯〉**的参赛资格。在赴华出征前夕，他特地寻找宿敌仓敷藏人交手，旨在通过直面未知的极致凶暴来打磨自身武道。在败给藏人的“火山碎屑流”后，诸星毫无颓唐，反而为对手的飞跃由衷赞叹，展现出顶级强者的宽广胸襟。
